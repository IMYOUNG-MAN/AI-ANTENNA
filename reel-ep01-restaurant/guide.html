1. 프론트엔드 / 백엔드

식당으로 치면 · 손님이 앉는 홀이 프론트엔드, 눈에 안 보이는 주방이 백엔드예요.
실제로는

프론트엔드는 화면에 보이고 내가 직접 누르는 부분이에요. 백엔드는 눈에 안 보이는 곳에서 그 요청을 받아 계산하고, 저장하고, 답을 만들어 주는 부분이죠. 우리가 쓰는 웹사이트나 앱은 거의 다 이 둘로 나뉘어서 서로 주고받으며 돌아가요.

이렇게 작동해요
  1. 내가 화면에서 버튼을 누른다
  2. 프론트엔드가 "이걸 해달라"는 요청을 만들어 보낸다
  3. 백엔드가 요청을 받아 처리하고, 필요하면 저장된 자료를 꺼낸다
  4. 결과를 프론트엔드로 돌려준다
  5. 프론트엔드가 그 결과를 화면에 그려 준다
AI 쓸 때 여기서 만나요

AI에게 "간단한 웹사이트 만들어 줘" 하면 화면 쪽 코드와 서버 쪽 코드를 나눠서 짜 줘요. 고쳐달라고 할 때 "화면 쪽만", "저장되는 쪽만"이라고 짚어 주면 훨씬 정확하게 움직이거든요.

✓

해보기 · 내가 매일 쓰는 앱을 둘로 쪼개 보기

자주 쓰는 앱 하나를 떠올려서 AI에게 물어보세요. 화면 쪽과 서버 쪽이 각각 무슨 일을 하는지 감이 잡혀요.

카카오톡에서 메시지 보내기 버튼을 누르면 프론트엔드와 백엔드가 각각 무슨 일을 하는지, 코딩 하나도 모르는 사람 기준으로 순서대로 설명해 줘.

2. API

식당으로 치면 · 손님 주문을 주방에 전하고, 다 된 요리를 가져다주는 웨이터예요.
실제로는

프로그램끼리 정해진 방식으로 요청과 답을 주고받는 창구예요. 상대 프로그램이 안에서 어떻게 돌아가는지 몰라도, "이렇게 물으면 이런 답이 온다"는 약속만 지키면 그 기능을 빌려 쓸 수 있죠. 날씨, 지도, 결제, AI까지 전부 이 방식으로 붙습니다.

이렇게 작동해요
  1. 내 프로그램이 정해진 주소로 요청을 보낸다
  2. 상대 서버가 요청이 약속대로 왔는지 확인한다
  3. 서버가 안에서 일을 처리한다
  4. 정해진 형식으로 결과를 돌려준다
  5. 내 프로그램이 그 결과를 받아 화면에 쓴다
AI 쓸 때 여기서 만나요

자동화 도구를 만지면 "API로 연결하세요"라는 안내를 꼭 만나요. AI 회사들도 클로드나 챗GPT를 API로 열어 둬서, 내가 만든 앱이나 엑셀 자동화에 AI를 갖다 붙일 수 있어요.

✓

해보기 · 내 일에 필요한 API 목록 뽑기

하고 싶은 자동화를 한 줄로 적고 물어보면, 뭘 붙여야 하는지 정리해서 알려 줘요.

매주 월요일에 지난주 매출을 정리해서 메일로 보내는 자동화를 만들고 싶어. 어떤 API가 필요하고 각각 무슨 일을 하는지 표로 알려 줘.

3. API 키

식당으로 치면 · 주방엔 직원 명찰 단 사람만 들어가죠. 그 명찰이 API 키예요.
실제로는

그 창구를 쓸 자격이 있는지 확인하는 비밀 문자열이에요. 누가 얼마나 썼는지 세는 이름표 노릇도 하거든요. 그래서 남에게 새면 남이 쓴 만큼 요금이 내 앞으로 쌓여요. 캡처, 단체 채팅, 공개된 코드에 붙여 넣으면 안 되는 이유죠.

이렇게 작동해요
  1. 서비스에 가입해서 키를 발급받는다
  2. 키를 내 컴퓨터 설정이나 비밀 메모에 저장한다
  3. 요청을 보낼 때 키를 같이 보낸다
  4. 서버가 키를 확인하고 사용량을 기록한다
  5. 맞으면 결과를 주고, 틀리면 거절한다
AI 쓸 때 여기서 만나요

Cursor 같은 도구나 자동화 서비스에 AI 모델을 붙일 때 "API Key"라고 적힌 빈 칸이 나와요. 거기에 붙여 넣는 긴 문자열이 바로 이거예요.

✓

해보기 · 키 보관 자리 미리 정해 두기

키를 만들기 전에 어디 둘지부터 정해 두면 사고가 안 나요. 비밀번호 관리 앱이나 나만 보는 메모 한 곳으로 정하고, 화면 공유할 때 그 창은 안 띄우기로 하세요.

API 키를 안전하게 보관하는 방법과, 실수로 남에게 노출됐을 때 바로 해야 할 일을 순서대로 알려 줘.

4. 터미널

식당으로 치면 · 주방에 직접 말로 지시하는 창구예요.
실제로는

마우스로 누르는 대신 글자로 컴퓨터에 명령을 넣는 검은 창이에요. 한 줄 치고 엔터하면 그 명령이 실행되고, 결과나 오류가 다시 글자로 나와요. 맥에서는 '터미널', 윈도우에서는 'PowerShell'이나 '명령 프롬프트'라는 이름으로 들어 있습니다.

이렇게 작동해요
  1. 터미널 앱을 켠다
  2. 지금 어느 폴더에 서 있는지 확인한다
  3. 명령을 한 줄 입력한다
  4. 엔터를 누르면 실행된다
  5. 결과나 오류 메시지가 글자로 나온다
AI 쓸 때 여기서 만나요

Claude Code는 창이 따로 없어요. 터미널 안에서 돌아가거든요. 그래서 설치 안내가 늘 "터미널을 열고 아래 줄을 붙여 넣으세요"로 시작해요.

✓

해보기 · 터미널 열고 한 줄만 쳐 보기

지금 내가 어느 폴더에 있는지 알려 주는 명령이에요. 아무것도 바꾸지 않고 보여만 주니까 마음 놓고 쳐 봐도 돼요.

맥: pwd   /   윈도우 PowerShell: Get-Location

5. 데이터베이스

식당으로 치면 · 재료를 정리해 쌓아 두고 필요할 때 꺼내 쓰는 창고예요.
실제로는

자료를 정해진 칸과 규칙에 맞춰 쌓아 두고, 필요한 것만 빠르게 찾아 꺼내는 프로그램이에요. 엑셀과 다른 점은 여러 사람이 동시에 넣고 꺼내도 자료가 안 깨지게 관리한다는 거죠. 회원 목록, 주문 내역, 게시글처럼 계속 쌓이는 건 다 여기로 들어가요.

이렇게 작동해요
  1. 어떤 칸에 무엇을 담을지 먼저 정한다
  2. 새 자료가 생기면 그 칸에 맞춰 넣는다
  3. 찾을 때는 조건을 걸어 필요한 줄만 꺼낸다
  4. 고치거나 지운 것도 규칙대로 반영된다
  5. 프로그램이 꺼낸 자료를 화면에 보여 준다
AI 쓸 때 여기서 만나요

AI에게 회원가입이 되는 사이트를 만들어 달라고 하면, 코드보다 먼저 "데이터베이스가 필요해요"라며 표 구조를 제안해요. 그 표가 바로 창고 칸을 짜는 작업이에요.

✓

해보기 · 내 업무 표를 칸부터 설계해 보기

지금 엑셀로 관리하는 목록 하나를 떠올려서 물어보세요. 무슨 칸이 필요하고 각 칸에 어떤 종류를 넣는지 정리해 줘요.

고객 이름, 연락처, 문의 날짜, 처리 상태를 관리하려고 해. 데이터베이스 표를 어떻게 만들면 좋을지 칸 이름과 자료 종류를 표로 보여 주고, 왜 그렇게 나눴는지도 한 줄씩 설명해 줘.

6. 깃

식당으로 치면 · 셰프가 레시피 바꿀 때마다 기록을 남기고, 별로면 전 레시피로 돌아가죠.
실제로는

파일이 바뀐 내용을 시점마다 기록해 두는 프로그램이에요. 언제 무엇을 어떻게 바꿨는지가 남으니까, 잘못되면 예전 상태로 되돌릴 수 있죠. 흔히 같이 듣는 깃허브는 그 기록을 인터넷에 올려 여러 사람이 같이 보는 서비스예요.

이렇게 작동해요
  1. 작업 폴더를 깃이 관리하게 시작한다
  2. 파일을 고친다
  3. 이번에 기록할 변경을 고른다
  4. "무엇을 왜 바꿨다" 한 줄 달아 저장한다
  5. 마음에 안 들면 예전 기록 지점으로 되돌린다
AI 쓸 때 여기서 만나요

Claude Code나 Cursor는 파일을 한 번에 여러 개 고쳐요. 깃이 깔려 있으면 결과가 별로일 때 손해 없이 되돌릴 수 있어서, 시작할 때부터 깃을 쓰라고 권하고 중간중간 "기록 남겨 둘까요?" 묻기도 해요.

✓

해보기 · 기록이 남아 있는지만 확인하기

깃이 관리하는 폴더에서 터미널에 쳐 보세요. 첫 줄은 지금 뭐가 바뀌었는지, 둘째 줄은 최근 기록 다섯 개를 보여 줘요. 둘 다 읽기만 하는 명령이에요.

git status   /   git log --oneline -5

7. 토큰

식당으로 치면 · 냄비에 한 번에 넣을 수 있는 양이 정해져 있죠. 그 양을 세는 단위예요.
실제로는

AI가 글을 다룰 때 잘게 쪼개는 조각의 개수를 세는 단위예요. 한글은 한 글자가 한두 조각쯤, 영어는 짧은 단어 하나가 한 조각쯤 돼요. AI가 한 번에 볼 수 있는 조각 수에 한계가 있고, API 요금도 보통 이 조각 수로 계산돼요.

이렇게 작동해요
  1. 내가 쓴 글이 조각으로 쪼개진다
  2. 앞선 대화와 붙여서 모델에 들어간다
  3. 한 번에 넣을 수 있는 양을 넘는지 확인한다
  4. 넘치면 앞부분이 잘리거나 새 대화를 권한다
  5. AI가 내놓는 답도 조각으로 나오고, 그만큼 같이 계산된다
AI 쓸 때 여기서 만나요

긴 문서를 통째로 붙여 넣었을 때 대화가 무거워지거나 앞에 한 말을 잊는 듯한 느낌, 그게 이 한계 때문이에요. API 요금표도 조각 단위로 적혀 있어요.

✓

해보기 · 긴 문서는 잘라서 넣어 보기

문서를 다 넣기 전에 필요한 부분만 남기라고 시켜 보세요. 답도 빨라지고 헤매지 않아요.

이 문서에서 결론과 숫자만 남기고 500자로 줄여 줘. 나머지 배경 설명은 버려도 돼.

8. MCP

식당으로 치면 · 배달앱, 결제기, 예약을 가게에 한 가지 방식으로 연결하는 거예요.
실제로는

AI를 외부 도구나 자료에 붙이는 방법을 하나로 통일한 규격이에요. 도구마다 연결 방식을 새로 만들지 않고, 이 규격을 지키는 도구는 이 규격을 지원하는 AI 앱에 똑같은 방법으로 붙어요. 앤트로픽이 규격과 코드를 무료로 공개해서 다른 회사 도구에도 쓰이고 있어요.

이렇게 작동해요
  1. 붙이고 싶은 도구의 연결 프로그램을 준비한다
  2. AI 앱 설정에 그 도구를 등록한다
  3. AI가 그 도구로 무엇을 할 수 있는지 목록을 받는다
  4. 필요한 순간에 AI가 알아서 그 도구를 부른다
  5. 돌아온 결과를 답에 섞어서 내놓는다
AI 쓸 때 여기서 만나요

Claude Code나 클로드 데스크톱 설정에 "MCP 서버 추가" 항목이 있어요. 내 파일, 노션, 깃허브처럼 AI가 직접 들여다봤으면 하는 걸 붙일 때 쓰는 자리예요.

✓

해보기 · 내 업무에 붙일 도구 골라 보기

연결부터 하려 들면 헤매요. 먼저 뭘 붙이면 이득인지 목록을 받아 보세요.

나는 사무직이고 문서 정리와 일정 관리에 시간을 많이 써. MCP로 AI에 붙이면 좋을 도구를 5개 추천하고, 각각 뭘 자동으로 시킬 수 있는지 한 줄씩 써 줘.
