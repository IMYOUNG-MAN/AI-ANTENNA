준비물

  • Claude Code — 유료 플랜 필요
  • Unreal Engine 5 — 무료
  • Blender 5.1 이상 — 무료
  • Meshy 계정 — API 키 발급

순서

1

세 프로그램을 설치합니다

Claude Code, Unreal Engine 5, Blender 5.1 이상을 각각 받아 깝니다.

✓ 세 프로그램이 모두 열립니다

2

블렌더와 Meshy를 채팅창에 붙입니다

블렌더는 MCP 애드온으로, Meshy는 Meshy MCP에 API 키를 넣어 연결합니다.

✓ 도구 목록에 블렌더와 Meshy가 보입니다

3

아이디어를 다섯 개 받아 하나를 고릅니다

아래 문장을 채팅창에 붙여넣고, 뜬 목록에서 하나를 골라 번호로 답합니다.

게임 아이디어를 다섯 개 내 주세요. 혼자 숲길을 뛰어다니는 3인칭 게임 쪽으로 부탁합니다. 아직 아무것도 만들지 말고 목록만 보여 주세요. 제가 하나를 고르면 그 아이디어를 레벨 구성, 등장 캐릭터, 필요한 소품 목록까지 자세히 늘려 주세요.

✓ 아이디어 다섯 개가 목록으로 뜹니다

4

캐릭터와 소품을 만들어 블렌더로 옮깁니다

그래픽카드 이름을 적은 뒤 아래 문장을 붙여넣습니다. Meshy가 만들고 블렌더가 받습니다.

제 그래픽카드는 (여기에 그래픽카드 이름을 적습니다)입니다. 이 성능으로 돌아가는 선까지 그래픽을 올려 주세요. 앞에서 정한 아이디어대로 Meshy에서 주인공 캐릭터와 소품을 만들고, 블렌더로 가져와 크기와 재질을 정리해 주세요.

✓ 블렌더 화면에 캐릭터와 소품이 올라옵니다

5

언리얼로 합쳐 직접 플레이합니다

아래 문장을 붙여넣으면 지형과 조명, 체력 표시까지 언리얼에서 완성됩니다.

블렌더에서 정리한 것들을 언리얼로 옮겨 한 판을 완성해 주세요. 숲길 지형과 조명, 3인칭 조작, 체력 표시, 화면 구석 작은 지도까지 넣어 주세요. 다 되면 바로 실행해 볼 수 있게 해 주세요.

✓ 언리얼에서 숲길을 뛰어다닙니다

여기서 막힙니다

한 판을 만드는 데 시간과 사용량이 훅 빠집니다. 작성자는 네 시간, 주간 Max 플랜의 19%를 썼습니다.

첫 판만 공들여 끝내고, 다음 판은 이미 만든 캐릭터와 소품을 다시 씁니다.

전투에 적까지 한 번에 넣어 달라고 하면 작업이 엉킵니다.

한 번 플레이해 본 뒤 전투, 적, 퀘스트를 한 번에 하나씩만 요청합니다.
