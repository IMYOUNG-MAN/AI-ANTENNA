클로드 코드 한도 끝나도 무료 AI로 이어 쓰는 법 — FreeLLMAPI

FreeLLMAPI를 내 컴퓨터에 띄우고 무료 AI 서비스 키를 넣어 두면, 클로드 코드가 한도에 막힐 때 다음 무료 모델로 알아서 넘어가서 작업을 이어 가요. 넘어갈 때 짧은 메모를 남겨서 하던 맥락도 이어 가요. 무료 제공사 34곳, 한 달 약 74억 토큰이에요.

준비물

  • 윈도우·맥·리눅스 (Node 20 이상이면 어디서든)
  • 무료 AI 서비스 계정 몇 개 — 이메일 가입, 대부분 카드 필요 없음
  • Claude Code (연결할 도구)
  • 무료 · 오픈소스(MIT)

사용 방법

1

FreeLLMAPI 설치

윈도우는 아래 '설치 파일' 주소에서 FreeLLMAPI-Setup-버전.exe를 받아 실행하는 게 가장 쉬워요. 작업 표시줄 아이콘으로 공유기처럼 켜져 있고, 대시보드가 브라우저로 열려요. 처음에 대시보드를 지킬 이메일·비밀번호를 정해요(내 컴퓨터 안에서만 써요).

2

무료 AI 키 넣기

대시보드 '열쇠' → '키 추가'에서 무료 서비스 키를 하나씩 넣어요. 처음엔 Groq·OpenRouter·Cerebras·Mistral처럼 카드 없이 받는 곳 두세 개면 충분해요. 받는 주소는 아래 '키 받는 곳'에 있어요. 제미나이 키는 결제를 연결하지 않은 프로젝트에서 만든 것만 무료예요.

3

Claude Code에 연결

대시보드 '에이전트'의 Claude Code 칸에 있는 한 줄을 복사해 터미널에 붙여 넣으세요. 기존 설정을 백업한 뒤 FreeLLMAPI를 가리키게 바꿔 줘요. 되돌리고 싶으면 백업된 설정으로 돌아가면 돼요.

4

그다음은 알아서

평소처럼 Claude Code를 쓰면, 한 모델이 한도(429)에 걸리는 순간 다음으로 좋은 무료 모델로 넘어가요. '모델' 화면에서 라우팅 전략(균형·빠름·똑똑함 등)과 순서를 바꿀 수 있어요.

막힐 때

  • 답이 이상하게 느려지거나 덜 똑똑해졌어요
    무료 묶음엔 최상위 모델이 없고, 늦은 시간엔 좋은 모델의 하루 한도가 먼저 차요. 한도는 UTC 자정(한국 오전 9시)에 초기화돼요.
  • 키를 넣었는데 그 업체로 안 가요
    '열쇠'에서 키 테스트를 눌러 보세요. 무료 등급이 없어진 업체(SambaNova 등)나 결제 수단을 요구하는 곳도 있어요.
  • 원래 클로드로 돌아가고 싶어요
    setup-claude가 바꾸기 전에 설정을 백업해 둬요. 백업된 설정으로 돌리거나 Claude Code 설정에서 주소를 지우면 돼요.

꼭 알고 쓰기

  • 클로드 모델이 무료가 되는 건 아니에요. 클로드 코드라는 도구에 다른 무료 모델을 붙이는 거예요.
  • 내 코드와 질문이 여러 무료 업체로 넘어가요. 회사 코드·개인정보에는 쓰지 마세요. 일부 키 없는 업체는 입력을 학습에 쓴다고 밝혀요.
  • README에도 '개인 실험·학습용이지 실제 서비스용이 아니다', '각 업체 약관을 지켜야 한다'고 적혀 있어요.
  • 프리미엄(연 19달러)은 최신 모델 목록을 더 빨리 받는 옵션이에요. 무료판도 매달 목록이 갱신돼요.
