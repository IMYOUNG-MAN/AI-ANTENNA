클로드한테 캡컷 컷 편집·자막 맡기는 법

Claude Code에 캡컷 편집 스킬(capcut-cli)을 넣으면, 원본 영상과 대본만 주고 "무음 자르고 자막 달아서 캡컷 프로젝트로 만들어 줘"라고 하면 끝나요. 캡컷을 열면 컷과 자막이 트랙마다 따로 들어와 있어서 그대로 손볼 수 있어요.

준비물

  • Claude Code (Claude Pro 이상 요금제)
  • Node.js 18 이상 (nodejs.org에서 LTS 설치)
  • 캡컷 PC 버전(무료) · 윈도우·맥
  • 편집할 원본 영상, 그리고 자막으로 쓸 대본(txt)

사용 방법

1

capcut-cli 설치

명령 프롬프트(맥은 터미널)에 아래 '설치'를 붙여 넣으세요. 그다음 'capcut doctor'를 치면 캡컷 프로젝트 폴더를 찾았는지 알려 줘요.

2

클로드에 스킬 넣기

Claude Code 입력창에 아래 '스킬 넣기' 두 줄을 한 줄씩 넣으세요. 클로드가 캡컷 명령을 모두 배워요.

3

편집 시키기

원본 영상과 대본.txt를 한 폴더에 두고, 그 폴더에서 claude를 실행해 아래 '편집 요청'을 붙여 넣으세요. 편집하는 동안 캡컷은 꺼 두세요(켜 두면 캡컷이 덮어써요).

4

캡컷에서 열기

캡컷을 켜면 홈에 새 프로젝트가 보여요. 열면 영상 컷과 자막이 트랙별로 들어와 있어서 글꼴·위치만 바꾸고 내보내면 돼요.

복사해서 쓰기

설치

명령 프롬프트에 한 줄

npm install -g capcut-cli

스킬 넣기

Claude Code 입력창에 한 줄씩

/plugin marketplace add renezander030/capcut-cli
/plugin install capcut-cli@capcut-cli

편집 요청 (영상에서 쓴 문장)

파일 이름만 바꿔서

원본.mp4에서 말 없는 구간은 다 잘라 내고, 대본.txt 대사로 자막 달아서 캡컷 프로젝트 '계란토스트'로 만들어 줘. 다 되면 미리보기.mp4도 뽑아 줘

숏폼으로 자르기

긴 영상에서

원본.mp4에서 제일 재밌는 30초를 골라 9:16 쇼츠 캡컷 프로젝트로 만들어 줘

막힐 때

  • '캡컷이 켜져 있다'며 멈춰요
    캡컷을 완전히 끄고 다시 시키세요. 켜진 동안에는 프로젝트가 덮어써질 수 있어서 일부러 멈춰요.
  • 대본이 없어요
    Whisper(무료 받아쓰기)를 깔면 대본 없이도 자막을 만들어요. 'capcut doctor'가 설치 방법을 알려 줘요.

주의할 점

  • 캡컷 공식 도구가 아니에요(개인 개발자 오픈소스, MIT). 캡컷이 업데이트되면 잠깐 안 될 수 있어요.
  • 편집 전 원본 프로젝트는 복사해 두세요. 클로드는 바꾸기 전에 .bak 백업을 남겨요.
  • 캡컷 Pro 전용 효과는 이 방법으로도 Pro가 필요해요.
