개인정보처리방침

적용 대상: AI Antenna 메일 도우미(AI Antenna가 자기 업무용 Gmail 계정에서만 쓰는 내부 도구). 시행일 2026-11-04.

1. 접근하는 정보

Google 계정 승인을 받아 AI Antenna 업무용 Gmail 계정의 메일(보낸 사람, 제목, 본문)을 읽고, 같은 계정에 답장 초안을 만들어요. 권한: gmail.readonly, gmail.compose.

2. 쓰는 목적

협업 제안 메일을 분류·요약하고 답장 초안을 만드는 데만 써요. 광고, 판매, 프로필 분석, 모델 학습에 쓰지 않아요.

3. 처리와 보관

운영자 PC에서 처리해요. 요약과 초안을 만들 때 메일 내용이 AI 모델(Anthropic Claude)로 전달돼요. 요약은 운영자 본인의 메신저로만 보내고, 처리 기록은 운영자 PC에만 남겨요. 제3자에게 팔거나 넘기지 않아요.

4. Google API 데이터

Google API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

5. 접근 해제

Google 계정 → 보안 → 타사 앱 연결에서 언제든 접근을 끊을 수 있어요.
