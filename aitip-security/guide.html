코드 보안 점검 플러그인 설치하고 쓰는 법

Claude Code에 보안 점검 플러그인을 붙이면, 보안 전문 에이전트가 프로젝트 코드를 읽고 위험한 곳을 심각도 순으로 파일·줄 번호와 함께 정리해 줘요. 고친 코드 예시까지 받을 수 있어요.

준비물

  • Claude Code (Codex CLI · Cursor도 가능)
  • 점검할 내 프로젝트 폴더
  • 무료 오픈소스 · MIT (wshobson/agents)

사용 방법

1

설치 (Claude Code)

Claude Code 입력창에 '설치 두 줄'을 한 줄씩 넣으세요. 94개 플러그인 모음 중 보안 점검(security-scanning)만 골라 설치해요.

2

점검 요청

프로젝트 폴더에서 Claude Code를 켜고 아래 '점검 요청'을 넣으세요. security-auditor 에이전트가 코드를 처음부터 끝까지 읽고 보고서를 써요.

3

보고서 보기

SECURITY-REPORT.md가 생겨요. Critical(아주 위험)부터 순서대로 보고, 가장 위험한 것부터 고치세요.

4

고치기

'C-01 고쳐 줘'처럼 하나씩 맡기세요. 한꺼번에 고치면 무엇이 바뀌었는지 보기 어려워요.

복사해서 쓰기

설치 두 줄

Claude Code 입력창에 한 줄씩

/plugin marketplace add wshobson/agents
/plugin install security-scanning@claude-code-workflows

점검 요청 (영상에서 쓴 그대로)

보고서만 받기

security-auditor 에이전트로 [폴더 이름] 폴더 보안 점검해 줘. 찾은 문제를 심각도 순으로 파일·줄 번호와 함께 SECURITY-REPORT.md에 한국어로 정리하고, 가장 위험한 3개는 고친 코드 예시도 붙여 줘. 코드 파일은 고치지 마.

올리기 전 점검

배포 직전

security-auditor 에이전트로 이번에 바꾼 파일만 보안 점검해 줘. 비밀번호·키가 코드에 들어갔는지, 로그인 없이 열리는 주소가 있는지 먼저 봐 줘.

막힐 때

  • 에이전트를 못 찾는대요
    설치 후 Claude Code를 껐다 켜고 '/agents'로 security-auditor가 보이는지 확인하세요.
  • 보고서를 다 믿어도 되나요?
    코드를 읽고 찾는 정적 점검이라, 실제로 돌려 봐야 아는 문제는 빠질 수 있어요. 결제·개인정보를 다루는 서비스라면 전문가 점검도 같이 받으세요.

더 잘 나오게

  • 같은 모음에 코드 리뷰, 테스트, 파이썬·자바스크립트 개발 플러그인도 있어요. '/plugin'에서 목록을 볼 수 있어요.
  • 영상 속 쇼핑몰 코드는 일부러 취약하게 만든 시연용 가짜 코드예요.
