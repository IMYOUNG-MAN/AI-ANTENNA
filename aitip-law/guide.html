AI에 법제처 연결하기 (korean-law-mcp)

AI가 법 조항을 기억으로 말하는 대신, 법제처 국가법령정보에서 원문을 직접 꺼내 오고 판례 사건번호가 실제로 있는지 검증해요. 현행 조문과 시행일까지 같이 보여 줘요.

준비물

  • 법제처 Open API 인증키(OC) — 무료
  • Claude Code 또는 Claude 앱 (ChatGPT·Cursor 등도 가능)
  • 무료 오픈소스 · MIT (chrisryugj/korean-law-mcp)

사용 방법

1

인증키(OC) 받기

open.law.go.kr에 가입하고 로그인한 뒤 'Open API 사용 신청'을 하면 인증키(OC)가 나와요. 보통 가입한 아이디예요.

2

Claude Code에 연결

Claude Code 입력창에 '설치 두 줄'을 넣으면 설치 중에 인증키를 물어봐요. 받은 OC를 넣으면 끝이에요.

3

Claude 앱(웹)에 연결

설정 → 커넥터 → 커스텀 커넥터 추가에 아래 '웹 커넥터 주소'를 넣고, 끝의 본인키 자리에 OC를 넣으세요.

4

물어보기

'근로기준법 제60조 알려 줘'처럼 물으면 법제처에서 원문을 꺼내 와요. 판례 번호를 받았다면 '인용 검증해 줘'를 붙이세요.

복사해서 쓰기

설치 두 줄 (Claude Code)

입력창에 한 줄씩

/plugin marketplace add chrisryugj/korean-law-mcp
/plugin install korean-law@korean-law-marketplace

웹 커넥터 주소

Claude 앱·웹

https://mcp.gomdori.app/law?oc=본인키

영상에서 넣은 질문

원문 + 판례 검증

퇴사할 때 못 쓴 연차휴가 수당 받을 수 있어? 근거 근로기준법 조문 원문이랑 대법원 판례 사건번호 2개 알려 줘. 법제처에서 직접 조회하고, 판례 번호는 인용 검증까지 해 줘. 짧게.

그날 기준 법

옛날 일이 문제일 때

[법 이름] [조문]을 [날짜] 기준으로 알려 줘. 그 뒤에 바뀐 내용이 있으면 무엇이 바뀌었는지도.

막힐 때

  • '사용자 정보 검증에 실패'가 떠요
    open.law.go.kr의 신청 정보에 등록한 IP·도메인과 지금 쓰는 곳이 다를 때 나와요. 신청 정보에서 IP를 확인하세요.
  • 연결이 안 돼요(시간 초과)
    처음 연결할 때 프로그램을 내려받느라 오래 걸릴 수 있어요. Claude Code를 껐다 켜거나 '/mcp'로 다시 연결하세요.

더 잘 나오게

  • 법적 판단이 필요한 일은 반드시 국가법령정보센터 원문을 직접 확인하고, 중요한 일은 전문가와 상의하세요.
  • AI가 쓴 글에 들어간 조문·판례가 진짜인지 검사하는 데도 쓸 수 있어요('이 글의 인용 검증해 줘').
