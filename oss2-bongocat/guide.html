BongoCat 설치법 + 고양이 위치·크기 바꾸는 법

화면 구석에 앉은 고양이가 내 키보드·마우스 입력에 맞춰 같이 두드려요. 무료, 회원가입 없음, 설정은 한국어.

준비물

  • 윈도우 또는 맥 컴퓨터 (저희는 윈도우 11에서 확인했어요)
  • 무료 · Apache-2.0 오픈소스

사용 방법

1

설치 파일 받기

github.com/ayangweb/BongoCat 의 오른쪽 'Releases'에서 최신 버전을 누르세요. 윈도우는 'BongoCat_버전_x64.exe', 맥은 '.dmg' 파일을 받아 실행하면 돼요.

2

처음 켜면 뜨는 안내

'관리자 권한으로 실행을 권장합니다' 창이 떠요. 저희는 닫고 그냥 썼는데, 메모장·브라우저에서 치는 키에는 잘 따라 쳤어요.

3

고양이를 오른쪽 클릭 → 설정

고양이 위에서 오른쪽 클릭하면 '설정 / 모델 창 / 업데이트 확인 / BongoCat 종료' 메뉴가 나와요. 끌 때도 여기서 'BongoCat 종료'를 누르세요.

4

고양이 바꾸기: 모델 라이브러리

설정 → 모델 라이브러리에서 standard(마우스+키보드), keyboard(키보드만), gamepad(게임패드) 중 '사용'을 누르면 바로 바뀌어요.

5

크기·투명도: 모델 창 → 창 외관

'창 크기 배율'의 + − 로 고양이 크기를, '창 불투명도'로 투명한 정도를 바꿔요. 기본값은 둘 다 100이에요.

6

위치 옮기기

공식 설명에 따르면 고양이를 마우스로 끌어서 원하는 곳에 두면 돼요. '모델 창 → 창 동작'의 '화면 안에 유지'를 켜 두면 화면 밖으로 안 나가요.

타자 칠 때마다 옆에서 같이 두드려서 덜 심심해요

모델: standard

게임할 때

게임패드 버튼에 맞춰 같이 누르는 고양이

모델: gamepad

화면 가리는 게 신경 쓰일 때

마우스를 올리면 잠깐 숨거나, 클릭이 고양이를 통과하게

모델 창 → 마우스를 올리면 숨기기 / 마우스 클릭 통과

방송·화면 녹화할 때

다른 창 뒤로 숨지 않게

모델 창 → 항상 맨 위 (기본 켜짐)

막힐 때

  • 어떤 프로그램에서는 고양이가 안 따라 쳐요
    그 프로그램이 관리자 권한으로 실행 중일 수 있어요. 처음 안내대로 BongoCat 아이콘을 오른쪽 클릭 → '관리자 권한으로 실행'으로 켜 보세요.
  • 고양이가 클릭을 가로막아요
    설정 → 모델 창 → '마우스 클릭 통과'를 켜면 고양이 뒤에 있는 것을 바로 누를 수 있어요.
  • 스팀에 있는 봉고캣이랑 같은 건가요?
    아니에요. 스팀의 'Bongo Cat'은 다른 회사가 만든 게임이고, 이건 GitHub에 코드가 공개된 무료 오픈소스 앱이에요.
  • 키 입력을 어디로 보내진 않나요?
    공식 설명에 따르면 인터넷 연결 없이 작동하고 사용자 데이터를 수집하지 않아요. 코드가 공개돼 있어 누구나 확인할 수 있어요.
