QuickLook 설치법 + 워드·엑셀 미리보기

윈도우 탐색기에서 파일을 고르고 스페이스바만 누르면, 열지 않고 바로 안을 봐요. 플러그인 하나를 더하면 워드·엑셀 파일도 미리 볼 수 있어요.

준비물

  • 윈도우 10 또는 11 컴퓨터
  • 무료 · 회원가입 없음 (GPL-3.0 오픈소스)

사용 방법

1

마이크로소프트 스토어에서 설치한다

시작 메뉴에서 'Microsoft Store'를 열고 'QuickLook'을 검색해 설치하세요. 스토어로 깔면 업데이트도 자동이에요. 스토어를 못 쓰는 PC는 github.com/QL-Win/QuickLook 의 Releases에서 설치 파일(.exe)을 받으면 돼요.

2

한 번 실행해 둔다

설치 후 QuickLook을 한 번 켜면 작업표시줄 오른쪽 아래 숨은 아이콘에 들어가 있어요. 창은 따로 안 떠요. 켜져 있어야 스페이스바가 먹어요.

3

파일을 고르고 스페이스바

탐색기에서 파일을 한 번 클릭해 고른 다음 스페이스바를 누르면 미리보기 창이 떠요. 사진·영상·PDF·압축파일(안에 든 파일 목록)까지 바로 보여요.

4

방향키로 다음 파일, 스페이스바로 닫기

미리보기를 띄운 채로 방향키를 누르면 옆 파일로 넘어가요. 다시 스페이스바(또는 Esc)를 누르면 닫혀요. 제대로 열고 싶으면 Enter예요.

5

워드·엑셀도 보려면 플러그인 추가

github.com/QL-Win/QuickLook.Plugin.OfficeViewer 의 Releases에서 'QuickLook.Plugin.OfficeViewer.qlplugin' 파일을 받으세요. QuickLook이 켜진 상태에서 그 파일을 고르고 스페이스바 → 뜨는 창에서 'Install' → QuickLook을 껐다 켜면 끝이에요.

이렇게 써 보세요

메일 첨부파일 여러 개 확인

받은 파일 폴더에서 하나 고르고 스페이스바, 방향키로 쭉 넘기기

스페이스바 → 방향키 → 스페이스바

압축파일 안에 뭐가 들었나

풀기 전에 파일 목록만 확인

zip 파일 고르고 스페이스바

엑셀 숫자만 슬쩍 확인

엑셀을 켜지 않고 표 내용만 볼 때 (플러그인 필요)

xlsx 고르고 스페이스바

영상 앞부분 확인

파일 이름만으론 뭔지 모를 때, 미리보기 창에서 바로 재생

mp4 고르고 스페이스바

막힐 때

  • 스페이스바를 눌러도 아무 일이 없어요
    QuickLook이 꺼져 있는 거예요. 시작 메뉴에서 QuickLook을 한 번 실행하세요. 작업표시줄 숨은 아이콘에 보이면 켜진 상태예요.
  • 한글(HWP) 파일은 안 보여요
    기본으로는 HWP 미리보기를 지원하지 않아요. 한글 파일은 저희가 소개한 rhwp(크롬에서 HWP 열기)를 써 보세요.
  • 처음 PDF를 볼 때 1초쯤 걸려요
    첫 미리보기만 잠깐 로딩이 돌고, 그다음부터는 바로 떠요.
  • 워드·엑셀 플러그인은 오피스가 있어야 하나요?
    공식 설명에는 마이크로소프트 오피스가 없어도 된다고 나와 있어요. (저희 PC에는 오피스가 있어서 '없는 상태'는 직접 확인하지 못했어요.)

더 잘 나오게

  • 맥의 '훑어보기(Quick Look)'를 윈도우로 옮겨 온 무료 오픈소스예요.
  • 마이크로소프트의 무료 도구 PowerToys에도 비슷한 'Peek'(Ctrl+스페이스바)이 있어요. QuickLook은 스페이스바 하나로 쓰고, 플러그인으로 볼 수 있는 파일 종류를 늘릴 수 있어요.
