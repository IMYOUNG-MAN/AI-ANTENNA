코딩 AI 규칙 파일(AGENTS.md) 템플릿

프로젝트 폴더에 규칙 파일 하나만 두면, 코딩 AI가 매번 내 방식대로 코드를 짜요. 매번 '타입스크립트로', '테스트도 써 줘'라고 다시 말할 필요가 없어요.

준비물

  • 코딩 AI 하나: Codex · Cursor · GitHub Copilot · Gemini CLI · Claude Code 등
  • 내 프로젝트 폴더

사용 방법

1

파일 만들기

프로젝트 맨 위 폴더에 AGENTS.md라는 이름으로 새 파일을 만드세요. 아래 템플릿 중 하나를 복사해 붙여 넣고 내 프로젝트에 맞게 고치세요.

2

Claude Code를 쓴다면

Claude Code는 CLAUDE.md를 읽어요. 같은 내용을 CLAUDE.md로 저장하거나, CLAUDE.md 안에 'AGENTS.md를 따른다'고 한 줄 적어 두세요.

3

짧게 유지하기

규칙은 10줄 안팎이 좋아요. 길게 쓸수록 중요한 규칙이 묻혀요. AI가 자꾸 틀리는 것만 한 줄씩 더하세요.

4

확인하기

새 대화에서 간단한 함수를 부탁해 보고, 규칙대로 나오는지 보세요. 안 지키는 규칙은 더 구체적으로 고치세요.

복사해서 쓰는 템플릿

영상에서 쓴 그대로

TypeScript 웹 프로젝트

# AGENTS.md — 이 프로젝트에서 코드를 짤 때 지킬 것
- 언어: TypeScript. any 쓰지 않기
- 함수 하나는 20줄 이내, 이름은 하는 일 그대로
- 외부 라이브러리 새로 넣지 않기
- 주석은 한국어로, 꼭 필요한 곳에만
- 코드 아래 테스트 3개(정상·경계·오류)를 같이 쓰기
- 설명은 코드 밖에 3줄 이내

파이썬 프로젝트

데이터·자동화 스크립트

# AGENTS.md
- 언어: Python 3.12, 타입 힌트 꼭 쓰기
- 함수 하나는 30줄 이내
- 새 패키지는 먼저 물어보고 넣기
- 파일 경로는 pathlib로
- 함수마다 pytest 테스트 2개 이상
- 설명은 코드 밖에 3줄 이내

처음 코딩하는 사람용

설명을 많이 듣고 싶을 때

# AGENTS.md
- 코드를 바꾸기 전에 무엇을 바꿀지 한국어로 먼저 짧게 말하기
- 한 번에 파일 하나만 고치기
- 어려운 용어는 괄호 안에 쉬운 말로 풀기
- 실행하는 방법을 마지막에 한 줄로 알려 주기
- 지우는 작업은 하기 전에 꼭 물어보기

막힐 때

  • 규칙을 안 지켜요
    새 대화에서 다시 해 보세요. 이전 대화 내용이 규칙보다 앞설 때가 있어요. 그래도 안 되면 규칙을 '~하지 말 것'보다 '~할 것'으로 구체적으로 바꿔 보세요.
  • ChatGPT 웹에서도 되나요?
    웹 채팅은 폴더를 읽지 않아요. 대신 '맞춤 설정(사용자 지침)'에 같은 내용을 넣으면 비슷하게 쓸 수 있어요.
