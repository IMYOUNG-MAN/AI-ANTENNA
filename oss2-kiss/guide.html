KISS Translator 설치법 + 단축키·번역 언어 설정

영어 웹페이지 문단마다 한국어 번역이 바로 아래에 붙어요. 원문이 사라지지 않아서 원문과 번역을 같이 볼 수 있어요. API 키 없이 바로 돼요.

준비물

  • 크롬 또는 엣지 (PC)
  • 무료 · GPL-3.0 오픈소스

사용 방법

1

크롬 웹스토어에서 설치

크롬 웹스토어에서 'KISS Translator'를 검색해 '크롬에 추가'를 누르세요. 엣지는 엣지 애드온 스토어에 있어요. 설치할 때 '모든 웹사이트의 데이터 읽기' 권한을 묻는데, 페이지 글을 읽어야 번역할 수 있어서 필요한 권한이에요.

2

번역 언어를 한국어로 (처음 한 번)

처음엔 대상 언어가 중국어(简体中文)로 돼 있을 수 있어요. 확장 아이콘 → 설정 → 왼쪽 메뉴 '웹 번역' → [전역 규칙] 카드 아래 '수정' → '대상 언어'를 '한국어 - Korean'으로 → '저장'.

3

영어 페이지에서 번역 켜기

화면 왼쪽 가장자리의 번역 버튼(文A)에 마우스를 올리면 메뉴가 나와요. '이 페이지 번역'을 누르면 문단마다 한국어가 아래에 붙어요.

4

단축키로 더 빠르게

설정 → 개요에 나오는 기본 단축키예요. Alt+Q 이 페이지 번역, Alt+S 선택한 문장 번역, Alt+K 팝업 메뉴. 크롬 주소창에 chrome://extensions/shortcuts 를 치면 바꿀 수 있어요.

막힐 때

  • 번역이 중국어로 나와요
    위 2번처럼 '웹 번역 → 전역 규칙 → 수정 → 대상 언어'를 한국어로 바꾸고 저장하세요. 문장 하나만 번역하는 '선택 번역' 창은 언어 설정이 따로라, 그 창에서도 대상 언어를 한국어로 골라 주세요.
  • 번역 버튼이 안 보여요
    크롬 기본 페이지(새 탭, 설정 화면, 웹스토어)에서는 확장이 동작하지 않아요. 일반 웹사이트에서 써 보세요.
  • 유튜브 이중 자막은요?
    설정 → '자막 번역'에 유튜브 이중 자막 기능이 있어요. 다만 저희 녹화 환경에서는 자막이 불러와지지 않아 직접 확인하지 못했어요.

더 잘 나오게

  • 번역 서비스는 기본으로 Microsoft가 켜져 있어요. 설정 → 번역 서비스에서 바꿀 수 있어요.
  • 설정 화면이 한국어로 나와서 메뉴 찾기가 어렵지 않아요.
