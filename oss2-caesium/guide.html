Caesium 설치법 + 첨부 용량 맞추는 설정

사진 여러 장의 용량을 한 번에 줄여요. 저희가 여행 사진 20장(54.65MB)을 긴 쪽 1920px·화질 80으로 줄여 보니 5.36MB, 90%가 줄었어요. 인터넷에 올리지 않고 내 컴퓨터에서 처리해요.

준비물

  • 윈도우 10·11 (맥판도 공식 페이지에 있어요)
  • 무료 · GPL-3.0 오픈소스. 화면은 영어예요(아래에 메뉴 뜻을 적어 뒀어요)

사용 방법

1

GitHub에서 받기

github.com/Lymphatus/caesium-image-compressor → 오른쪽 Releases → 설치판 'win-setup.exe' 또는 설치 없는 'win-portable.zip'을 받으세요.

2

먼저 저장 위치 정하기 (원본 지키기)

오른쪽 Output 탭 → 'Same folder as input'(원본과 같은 폴더)을 켜고, Suffix(이름 끝)에 _small 처럼 적으세요. 원본은 그대로 두고 '사진이름_small.jpg'가 옆에 새로 생겨요.

3

사진 넣기

왼쪽 아래 'Add...'를 눌러 사진을 고르세요(여러 장 한 번에). 폴더째 넣으려면 위쪽 폴더 아이콘이에요.

4

크기 정하기 (용량이 가장 많이 줄어요)

Resize 탭 → 'Resize to fit'을 'Long edge'(긴 쪽 기준)로 → Size에 1920 → 'Do not enlarge'(작은 사진은 키우지 않기)를 켜세요. 폰 사진은 보통 4000px 넘어서 이것만으로 크게 줄어요.

5

화질 정하기

Compression 탭의 JPEG Quality가 80이면 눈으로 차이가 거의 없어요(기본값). 더 줄여야 하면 70 정도까지 내려 보세요.

6

Compress 누르기

목록 아래 'Compress'를 누르면 사진마다 초록 체크가 생기고, 끝나면 원래 용량·줄어든 용량·절약 %가 창으로 떠요. 저희는 20장에 15초쯤 걸렸어요.

상황별 설정

메일·메신저로 보낼 때

폰 화면으로 보기에 충분한 크기

Long edge 1920 · Quality 80

정부24·학교·회사 시스템 '첨부 용량 초과'

장당 용량 제한이 빡빡할 때

Long edge 1280 · Quality 70

인쇄하거나 크게 볼 사진

해상도는 두고 용량만 조금

Resize: No resize · Quality 85

용량이 오히려 커지는 사진

이미 많이 압축된 사진은 건너뛰기

Output → Skip if output size is bigger (기본 켜짐)

막힐 때

  • 영어 메뉴가 헷갈려요
    Compression = 화질, Resize = 크기, Output = 저장 위치, Compress = 줄이기 시작, Saved = 줄어든 비율이에요.
  • 원본이 바뀔까 걱정돼요
    Output 탭에서 'Same folder as input'과 Suffix(_small 등)를 먼저 정하면 원본은 그대로 두고 새 파일로 저장돼요. 'Move the original file'(원본 옮기기)은 꺼 두세요.
  • 용량이 별로 안 줄었어요
    화질만 낮추면 이미 압축된 사진은 10~20%만 줄어요(저희도 화질 80만으로는 13%). 크기(Resize)를 같이 줄여야 크게 줄어요.
  • 사용 기록을 보내나요?
    설정(톱니바퀴) → 'Send anonymous usage reports'가 기본으로 켜져 있어요. 원하지 않으면 끄세요. 사진 자체를 인터넷에 올리지는 않아요.
