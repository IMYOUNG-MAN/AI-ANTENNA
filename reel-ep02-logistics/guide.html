서버 터졌다는 말, 물류센터로 풀기

'서버 터졌다', '배포했다' 같은 말을 들었을 때 지금 어디서 무슨 일이 생긴 건지 그림이 그려져요.

전체 흐름

  1. 요청 — 내가 버튼을 누르면 요청 하나가 출발해요
  2. 트래픽 — 그 요청이 한꺼번에 몰리면 트래픽이 돼요
  3. 로드밸런서 — 입구에서 요청을 여러 서버로 나눠 보내요
  4. 서버 — 요청을 받은 서버가 처리해서 답을 만들어요
  5. 캐시 — 자주 나가는 답은 미리 챙겨둔 걸 바로 꺼내 줘요
  6. 스케일 아웃 — 그래도 벅차면 서버 대수를 늘려요
  7. 배포 — 고친 코드를 실제 서비스에 올려 돌려요
  8. 다운타임 — 그 와중에 멈춘 시간이 다운타임이에요

1. 서버

한 줄로 · 주문 오면 물건 꺼내서 보내주는 물류센터
실제로는

서버는 다른 컴퓨터가 보낸 요청을 받아 처리하고 결과를 돌려주는 컴퓨터예요. 보통 데이터센터에 놓여 24시간 켜져 있죠. 특별한 기계라서 서버인 게 아니라, 요청을 받아 답해주는 역할을 맡으면 서버라고 불러요.

이렇게 작동해요
  1. 내가 앱이나 웹에서 버튼을 눌러요
  2. 요청이 인터넷을 타고 그 서비스 주소로 가요
  3. 서버가 요청을 받아 계산하거나 데이터를 찾아요
  4. 만든 결과를 다시 내 화면으로 보내줘요
AI 쓸 때 여기서 만나요

챗GPT나 클로드에 문장을 보내면 답을 만드는 건 내 노트북이 아니라 그 회사 서버예요. 그래서 인터넷이 끊기면 아무 말도 돌아오지 않죠.

예를 들면

'서버 터졌다'는 요청이 너무 많거나 서버가 멈춰서 답이 안 돌아오는 상황이에요. 화면에는 '503' 같은 숫자나 '잠시 후 다시 시도해 주세요'가 뜨고요. 이럴 땐 내 쪽을 아무리 고쳐도 안 되고, 회사가 고칠 때까지 기다려야 해요.

2. 트래픽

한 줄로 · 그 센터로 오늘 쏟아지는 상자 백만 개
실제로는

트래픽은 일정한 시간 동안 서비스에 오가는 요청과 데이터의 양이에요. 사람이 많아도 늘고, 한 사람이 요청을 자주 보내도 늘어요. 서버가 버틸 수 있는 양을 넘기면 느려지거나 아예 거절하기 시작하죠.

이렇게 작동해요
  1. 사람들이 동시에 같은 서비스를 열어요
  2. 요청이 초당 수천, 수만 건씩 서버로 몰려요
  3. 서버가 받아낼 수 있는 양을 넘기면 줄이 생겨요
  4. 줄이 길어지면 느려지고, 더 넘치면 요청을 돌려보내요
AI 쓸 때 여기서 만나요

새 모델이 나온 날 클로드나 챗GPT가 유난히 느린 건 트래픽이 몰려서예요. 요금제에 사용 한도가 걸려 있는 것도 몰리는 양을 나눠 쓰려는 장치거든요.

예를 들면

콘서트 예매 시작 1분, 수강 신청 첫 10초에 화면이 멈추죠. 짧은 시간에 트래픽이 몰린 거예요. 평소 초당 100건 받던 서버에 갑자기 10만 건이 들어오면 장비가 멀쩡해도 못 버텨요.

3. 로드밸런서

한 줄로 · 입구에서 상자를 빈 컨베이어로 나눠주는 반장
실제로는

로드밸런서는 들어오는 요청을 여러 서버에 나눠 보내는 중간 담당이에요. 한 대에만 몰리지 않게 돌려 주고, 응답이 없는 서버는 명단에서 빼버려요. 그래서 서버 한 대가 죽어도 서비스는 계속 돌아가죠.

이렇게 작동해요
  1. 내 요청이 서비스 주소로 들어와요
  2. 로드밸런서가 지금 여유 있는 서버를 하나 골라요
  3. 그 서버로 요청을 넘겨요
  4. 서버가 만든 답이 로드밸런서를 지나 내 화면으로 와요
  5. 응답 없는 서버는 명단에서 빼고 다음부터 보내지 않아요
AI 쓸 때 여기서 만나요

우리가 직접 만질 일은 거의 없지만, '일부 사용자만 오류'라는 공지의 정체가 바로 이거예요. 내 요청이 하필 상태가 나쁜 서버로 갔을 수 있죠.

예를 들면

옆자리 동료는 클로드가 잘 되는데 나만 계속 오류가 날 때가 있어요. 같은 주소로 들어갔는데 붙은 서버가 다른 거예요. 창을 닫고 다시 들어가면 다른 서버로 연결돼 그냥 풀리기도 합니다.

4. 스케일 아웃

한 줄로 · 넘치면 똑같은 센터를 옆에 하나 더 짓는 것
실제로는

스케일 아웃은 같은 일을 하는 서버를 여러 대로 늘려서 처리량을 키우는 방법이에요. 반대로 서버 한 대의 성능을 더 좋게 올리는 건 스케일 업이라고 불러요. 늘리기도 줄이기도 쉬워서 요즘 서비스는 대부분 스케일 아웃을 씁니다.

이렇게 작동해요
  1. 트래픽이 늘어 지금 서버로는 벅차요
  2. 똑같은 서버를 몇 대 더 켜요
  3. 로드밸런서 명단에 새 서버를 올려요
  4. 요청이 여러 대로 나뉘어 처리돼요
  5. 한가해지면 늘렸던 서버를 다시 꺼요
AI 쓸 때 여기서 만나요

AI 서비스가 '지금 용량이 부족합니다'라고 뜨다가 몇 분 뒤 멀쩡해지는 건 뒤에서 서버를 늘려서예요. 클라우드 요금이 쓴 만큼 오르는 이유도 여기 있고요.

예를 들면

쇼핑몰은 할인 시작 전에 서버를 몇 배로 늘려두고, 행사가 끝나면 다시 줄여요. 한 대로 초당 100건을 받는다면 열 대면 대략 1000건이 되죠. 이렇게 대수로 밀어붙이는 게 스케일 아웃이에요.

5. 캐시

한 줄로 · 제일 많이 나가는 물건을 문 앞에 미리 쌓아두기
실제로는

캐시는 자주 쓰는 결과를 가까운 곳에 저장해 두고 다시 꺼내 쓰는 방식이에요. 매번 처음부터 계산하거나 멀리서 가져오지 않으니 훨씬 빠르죠. 대신 원본이 바뀌었는데 저장해 둔 사본이 옛것이면 지난 화면이 그대로 보일 수 있어요.

이렇게 작동해요
  1. 누가 처음 요청하면 서버가 제대로 계산해요
  2. 그 결과를 캐시에 사본으로 남겨요
  3. 다음 사람이 같은 걸 요청하면 캐시에서 바로 줘요
  4. 서버까지 가지 않으니 응답이 빨라져요
  5. 정해진 시간이 지나거나 원본이 바뀌면 사본을 버리고 다시 받아요
AI 쓸 때 여기서 만나요

웹페이지를 분명히 고쳤는데 내 화면만 어제 것일 때, 브라우저가 남겨둔 캐시 때문이에요. 개발자용 API로 클로드를 쓸 때도 똑같이 긴 설명을 매번 보낼 땐 캐싱을 켜서 시간과 비용을 아껴요.

예를 들면

회사 공지가 바뀐 걸 아는데 내 브라우저에는 계속 옛 공지가 떠요. 강력 새로고침 한 번에 새 내용이 나오죠. 그동안 저장해 둔 사본을 보고 있었던 거예요.

6. 배포

한 줄로 · 새 분류기를 들여와 오늘부터 진짜로 돌리는 순간
실제로는

배포는 만든 코드를 실제 사용자가 쓰는 곳에 올려 돌리기 시작하는 일이에요. 내 컴퓨터에서만 되던 게 이때부터 남들에게도 보이죠. 올린 뒤 문제가 터지면 이전 버전으로 되돌리는데, 그걸 롤백이라고 불러요.

이렇게 작동해요
  1. 내 컴퓨터에서 코드를 고치고 돌려 봐요
  2. 고친 코드를 팀이 함께 쓰는 저장소에 올려요
  3. 시험용 환경에서 한 번 더 확인해요
  4. 문제 없으면 실제 서비스 서버로 올려요
  5. 이상하면 바로 전 버전으로 되돌려요
AI 쓸 때 여기서 만나요

Cursor나 Claude Code로 뭘 만들고 나서 '친구한테 링크로 보내고 싶다'는 생각이 드는 순간이 배포예요. 그때부터는 내 노트북이 꺼져도 돌아가야 하니 밖에 있는 서버에 올려야 하죠.

예를 들면

휴대폰 앱 업데이트 알림도 배포의 결과예요. '이번 버전에서 오류를 고쳤습니다'는 누군가 고친 코드를 배포했다는 뜻이고요. 반대로 새 기능이 나왔다가 몇 시간 뒤 슬쩍 사라졌다면 롤백한 겁니다.

7. 다운타임

한 줄로 · 기계 바꾸는 동안 센터가 멈춰 있는 시간
실제로는

다운타임은 서비스가 멈춰서 아무도 못 쓰는 시간이에요. 고장으로 생기기도 하고, 점검이나 교체를 하려고 일부러 멈추기도 해요. 요즘은 서버를 한 대씩 번갈아 바꿔 멈춤 없이 올리는데, 이걸 무중단 배포라고 합니다.

이렇게 작동해요
  1. 고장이나 점검으로 서버가 요청을 못 받아요
  2. 접속하면 오류 화면이나 점검 안내가 떠요
  3. 그 시간 동안 아무도 쓸 수 없어요 — 이게 다운타임이에요
  4. 고치고 다시 켜면 서비스가 돌아와요
  5. 서버를 한 대씩 돌려가며 바꾸면 이 멈춤을 없앨 수 있어요
AI 쓸 때 여기서 만나요

클로드나 챗GPT가 몇십 분 통째로 안 되는 때가 다운타임이에요. 회사 상태 페이지에 '장애 발생, 조치 중'으로 올라오고, 끝나면 복구된 시각까지 같이 적혀요.

예를 들면

서비스가 내세우는 '99.9%'라는 약속은 뒤집어 보면 한 달에 40분쯤은 멈출 수 있다는 뜻이에요. 그 40분이 마감 30분 전에 걸리면 뼈아프죠. 그래서 중요한 작업은 결과를 틈틈이 내 손에 챙겨둬야 해요.
