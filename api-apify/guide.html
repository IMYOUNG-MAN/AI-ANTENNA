Apify로 경쟁 계정 게시물 수치 한 번에 받기

공개 인스타 계정의 최근 게시물 좋아요·댓글·조회수를 표로 받아요. 코드를 몰라도 사이트에서 버튼으로 할 수 있고, 개발자라면 API로 자동화할 수 있어요.

준비물

  • Apify 계정 (무료 플랜: 카드 없이 가입, 매달 $5 사용분)
  • 분석할 공개 계정 이름

사용 방법

1

가입

apify.com에서 구글 계정으로 가입하세요. 무료 플랜은 카드 등록 없이 매달 $5만큼 쓸 수 있어요.

2

코드 없이 해 보기

Apify Store에서 'Instagram Scraper'(만든 곳: Apify)를 열고, 계정 주소(예: https://www.instagram.com/nasa/)를 넣고, 결과 종류를 posts, 개수를 30으로 두고 Start를 누르세요. 끝나면 Export에서 엑셀(CSV)로 받을 수 있어요.

3

API 키 받기 (자동화할 때)

오른쪽 위 Settings → API & Integrations에서 Personal API token을 복사하세요. 이 키는 비밀번호처럼 다루고, 남에게 보내거나 코드에 그대로 올리지 마세요.

4

코드로 부르기

아래 '바로 쓰는 코드'에서 내 키만 넣어 실행하면 같은 표를 받아요. 영상 속 화면도 이 방식으로 불렀어요.

5

비용 보기

무료 플랜에서 이 도구는 게시물 1,000개당 $2.70이에요. 계정 하나에 30개씩이면 약 $0.08이라, 무료 사용분으로 한 달에 60개 계정쯤 볼 수 있어요. 쓴 금액은 Billing에서 볼 수 있어요.

바로 쓰는 코드

터미널 한 줄 (curl)

결과를 바로 JSON으로

curl -X POST "https://api.apify.com/v2/acts/apify~instagram-scraper/run-sync-get-dataset-items?token=내_API_키" -H "Content-Type: application/json" -d '{"directUrls":["https://www.instagram.com/nasa/"],"resultsType":"posts","resultsLimit":30}'

Node.js

표로 정리해서 보기

const TOKEN = process.env.APIFY_TOKEN; // 키는 환경 변수로
const url = `https://api.apify.com/v2/acts/apify~instagram-scraper/run-sync-get-dataset-items?token=${TOKEN}`;
const res = await fetch(url, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ directUrls: ["https://www.instagram.com/nasa/"], resultsType: "posts", resultsLimit: 30 }),
});
const posts = await res.json();
console.table(posts.map((p) => ({ 날짜: p.timestamp?.slice(0, 10), 좋아요: p.likesCount, 댓글: p.commentsCount, 조회: p.videoPlayCount ?? "" })));

Python

판다스로 분석

import os, requests, pandas as pd
url = "https://api.apify.com/v2/acts/apify~instagram-scraper/run-sync-get-dataset-items"
body = {"directUrls": ["https://www.instagram.com/nasa/"], "resultsType": "posts", "resultsLimit": 30}
posts = requests.post(url, params={"token": os.environ["APIFY_TOKEN"]}, json=body, timeout=300).json()
df = pd.DataFrame(posts)[["timestamp", "type", "likesCount", "commentsCount", "videoPlayCount"]]
print(df.sort_values("likesCount", ascending=False).head(10))
df.to_csv("posts.csv", index=False, encoding="utf-8-sig")
