로고 디자인 스킬 설치하고 쓰는 법

Claude Code에 로고 디자인 스킬을 붙이면, 이름 한 줄로 로고 시안 3개를 SVG 파일로 받고 16px 테스트 시트까지 받아요. 마음에 드는 시안을 고르면 색·로고 조합·파비콘까지 키트로 이어서 만들어 줘요.

준비물

  • Claude Code (Codex CLI · Gemini CLI · Cursor도 가능)
  • Python 3 (스킬 안의 테스트 도구가 써요)
  • 무료 오픈소스 · MIT

사용 방법

1

설치 (Claude Code)

Claude Code 입력창에 아래 '설치 두 줄'을 한 줄씩 넣으세요. 플러그인 마켓에서 스킬을 받아 와요.

2

요청하기

'○○ 로고 만들어 줘'처럼 말하면 스킬이 알아서 켜져요. 처음엔 질문 몇 개를 하거나, '질문하지 말고 가정해서 바로 시안 3개'라고 하면 바로 만들어요.

3

시안 고르기

시안 3개를 한 장으로 모은 이미지와 추천 이유를 보여 주고 멈춰요. 마음에 드는 걸 고르고 '키트 만들어 줘'라고 하면 색 조합, 로고 배치, 파비콘·앱 아이콘까지 만들어요.

4

파일 확인

요청할 때 '파일은 out 폴더에'처럼 저장 위치를 말해 두면 찾기 쉬워요. SVG는 크기를 키워도 깨지지 않는 로고 파일이에요.

복사해서 쓰기

설치 두 줄

Claude Code 입력창에 한 줄씩

/plugin marketplace add kaankiziltug/logo-design-skill
/plugin install logo-design@logo-design-skill

영상에서 넣은 요청

바로 시안까지

동네 빵집 '밀담' 로고 만들어 줘. 질문하지 말고 가정을 밝힌 뒤 바로 시안 3개를 SVG로, 16px 테스트 시트와 시안 한눈에 보기 이미지까지. 파일은 out 폴더에.

카페·음식점

가게 로고

[가게 이름] 로고 만들어 줘. 업종은 [카페/식당], 분위기는 [따뜻한/깔끔한/고급스러운], 간판과 컵 홀더에 쓸 거야. 시안 3개를 SVG로, 한 색으로 찍었을 때도 보이게.

앱·서비스

앱 아이콘까지

[서비스 이름] 로고 만들어 줘. [한 줄 설명]. 앱 아이콘과 파비콘으로도 써야 하니 16px에서도 알아보게. 시안 3개 보여 주고 추천해 줘.

유튜브·인스타 채널

프로필 사진용

[채널 이름] 채널 로고 만들어 줘. 프로필 동그라미 안에 들어가야 하고, [주제] 채널이야. 글자 없는 심볼형 하나, 글자형 하나, 둘 섞은 것 하나.

막힐 때

  • 스킬이 안 켜져요
    설치 후 Claude Code를 껐다 켜세요. '/skills'를 입력하면 logo-design이 목록에 보여야 해요. 그래도 안 되면 요청에 '로고 디자인 스킬로'라고 붙여 보세요.
  • 테스트 시트 이미지가 안 만들어져요
    스킬 안의 도구가 Python 3를 써요. python --version으로 설치돼 있는지 확인하세요.

더 잘 나오게

  • 상표 등록 전에는 비슷한 로고가 없는지 특허청 키프리스(kipris.or.kr)에서 꼭 따로 확인하세요.
  • 스킬에 실제 로고 1,400개 자료가 들어 있어서, 같은 업종 로고들과 겹치지 않는지도 같이 봐 줘요.
