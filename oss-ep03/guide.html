Buzz 설치법 + 한국어 잘 받아 적는 설정

회의·강의 녹음을 넣으면 시간별로 글로 받아 적어 줘요. 인터넷 없이 내 컴퓨터에서만 돌아서 녹음이 밖으로 나가지 않아요.

준비물

  • 윈도우 PC 또는 애플 실리콘(M1 이후) 맥 — 인텔 맥은 옛 버전(1.4.5)까지만 돼요
  • 녹음 파일 (MP3·M4A·WAV, 영상 파일도 돼요)
  • 처음 한 번만 인터넷 — 음성 인식 모델을 내려받아요

사용 방법

1

설치 파일을 받는다

github.com/chidiwilliams/buzz/releases 에서 최신 버전을 받으세요. 윈도우는 Buzz-…-windows.exe와 .bin 파일 두 개를 같은 폴더에 받아 exe를 실행하면 돼요(합쳐 약 2.7GB). 맥은 README의 SourceForge 링크에서 .dmg를 받으세요.

2

설치하고 Buzz를 연다

처음 켤 땐 1~2분 걸릴 수 있어요. 화면은 영어지만 쓰는 버튼은 몇 개 안 돼요.

3

+ 버튼으로 녹음 파일을 넣는다

왼쪽 위 + (Import) 버튼을 누르고 파일을 고르세요. 여러 개를 한 번에 넣어도 돼요.

4

모델과 언어를 고르고 Run

아래 '한국어 잘 받아 적는 설정'대로 고른 뒤 Run을 누르세요. 처음엔 모델을 내려받느라 조금 더 걸려요.

5

목록에서 Completed가 뜨면 두 번 누른다

받아 적은 글이 시간별로 나와요. 틀린 글자는 칸을 눌러 바로 고칠 수 있어요.

6

Export로 저장한다

위쪽 Export에서 TXT(회의록), SRT·VTT(영상 자막) 중 고르세요.

한국어 잘 받아 적는 설정

처음엔 이 조합

저희 노트북에서 37초 회의가 28초, 7문장 중 틀린 곳 두 군데

Model: Whisper.cpp · Small · Language: Korean

더 정확하게

시간은 더 걸려도 받아쓰기 정확도가 중요할 때 (컴퓨터 사양이 높을수록 좋아요)

Model: Whisper.cpp · Medium 또는 Large-V3-Turbo

언어는 꼭 지정

자동 감지(Detect Language)보다 한국어로 정해 두는 게 안정적이에요

Language: Korean

느리면 엔진을 확인

같은 Small이라도 Whisper.cpp가 저희 PC에서 3배 빨랐어요 (Whisper 1분 27초 → Whisper.cpp 28초)

Model 종류: Whisper.cpp

영어 영상에 한국어 자막

Task를 Translate로 바꾸면 영어로 옮겨 적어요. 한국어 번역은 결과 화면의 Translate 기능을 쓰세요

결과 화면 → Translate

회의 실시간 받아쓰기

마이크 버튼을 누르면 말하는 대로 바로 글이 나와요

왼쪽 위 🎙 (Record) 버튼

막힐 때

  • 처음 켤 때 한참 안 떠요
    첫 실행 땐 준비하느라 1~2분 걸릴 수 있어요. 그래도 안 뜨면 컴퓨터를 다시 켜고 실행해 보세요.
  • 너무 느려요
    모델 종류를 Whisper.cpp로, 크기를 Small 이하로 낮추세요. 긴 녹음은 켜 두고 다른 일을 하면 돼요.
  • 글자가 많이 틀려요
    Language를 Korean으로 지정하고, 모델을 Medium으로 올려 보세요. 잡음이 많은 녹음은 정확도가 떨어져요.
  • 회사 회의 녹음을 넣어도 되나요?
    Buzz는 내 컴퓨터 안에서만 받아 적어서 녹음이 외부 서버로 가지 않아요. 다만 회사 보안 규칙은 먼저 확인하세요.

더 잘 나오게

  • 회의록으로 쓸 땐 TXT로 내보낸 뒤 챗GPT·클로드에 붙여 '결정 사항과 할 일만 정리해 줘'라고 하면 바로 요약돼요.
  • 녹음할 때 휴대폰을 말하는 사람 가까이 두면 정확도가 확 올라가요.
  • 영상 자막은 SRT로 내보내 캡컷·프리미어에 불러오면 돼요.
