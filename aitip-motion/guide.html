앱 설명 한 줄로 음악까지 들어간 소개 영상 — huashu-motion 쓰는 법

무료 오픈소스 스킬 huashu-motion을 Claude Code에 붙이면, 제품 이름과 설명 한 줄로 소개 영상을 만들어 줘요. 제품을 읽고 분위기를 정하고, 장면을 음악 마디에 맞춰 나누고, 악보를 직접 써서 음악을 넣고, 코드로 그린 장면을 MP4로 뽑아요. 고칠 장면은 화면을 콕 찍고 바꿀 내용만 쓰면 돼요.

준비물

  • Claude 유료 요금제 + Claude Code (코덱스 같은 다른 코딩 AI도 돼요)
  • Node.js(npx)·ffmpeg — 처음 실행 때 필요한 걸 스킬이 확인해요
  • 무료 · 오픈소스(MIT) · 영상 한 편에 20~40분

사용 방법

1

설치

명령 프롬프트에 아래 '설치' 한 줄을 넣으세요. 내 프로젝트 폴더에서만 쓰려면 저장소를 내려받아 .claude/skills 폴더에 huashu-motion 폴더째 넣어도 돼요.

2

한 줄로 요청

Claude Code에서 아래 '소개 영상' 문장을 보내세요. 제품 이름, 길이, 핵심 기능 두세 개, 원하는 분위기만 적으면 돼요. 방향 시안을 고르게 물어보는데, '질문하지 말고 네가 골라'라고 쓰면 알아서 정해요.

3

박자표와 음악

스킬이 먼저 박자표(treatment.md)를 만들어요. 장면마다 몇 초, 무엇이 나오는지, 음악 몇 마디인지 적혀 있어요. 음악은 악보부터 직접 쓰고 악기 소리로 연주해서 영상에 넣어요.

4

화면 찍어 고치기

편집기를 열면 영상 화면에서 C를 누르고 고칠 곳을 클릭한 뒤 바꿀 내용을 쓰면, 그 장면 그 부분만 고쳐요. 편집기 없이 '3초 장면 글자를 더 크게' 처럼 말로 해도 돼요.

복사해서 쓰기

설치

명령 프롬프트에

npx skills add alchaincyf/huashu-motion

소개 영상

Claude Code에 (괄호만 바꾸기)

/huashu-motion (앱·제품 이름)의 (20)초 소개 영상을 만들어 줘. 핵심: (기능 1), (기능 2), (기능 3). 분위기: (귀여운 미니멀 / 고급스러운 / 경쾌한). 화면 글자는 한국어. 음악까지 넣어서 MP4로 렌더해 줘.

발표 영상

발표 자료를 영상으로

/huashu-motion 이 발표 내용을 (30)초 요약 영상으로 만들어 줘. 장면마다 한 문장씩, 숫자는 크게. 내용: (…)

고치기

만든 뒤에

(3)초 장면의 (제목 글자)를 더 크게 하고, 마지막 장면은 (1)초 더 길게 해 줘. 나머지는 그대로.

막힐 때

  • 렌더 중에 멈추거나 실패해요
    윈도우에서는 흐림 효과 렌더가 임시 폴더 문제로 실패할 수 있어요(저희도 한 번 실패). '흐림 없이 다시 렌더해 줘'라고 하면 돼요.
  • 나레이션도 넣을 수 있나요?
    기본은 음악과 효과음만이에요. 목소리는 따로 녹음하거나 음성 AI로 만들어 붙이세요.

꼭 알고 쓰기

  • 영상 한 편에 20~40분 걸려요. 컴퓨터 성능에 따라 더 걸릴 수 있어요.
  • 실제 회사·브랜드 이름과 로고를 쓸 땐 권리가 있는지 확인하세요. 화면 속 '집중모드'는 시연용 가상 앱이에요.
