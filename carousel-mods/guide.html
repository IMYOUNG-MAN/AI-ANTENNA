클로드 코드 mods — 지우기 전 멈춤·대화량 날씨·다시 보기·말로 만들기

앤트로픽이 10월 1일 내놓은 클로드 코드 'mods'를 처음부터 붙이는 순서예요. 공식 샘플 3개(Blast Radius·Token Weather·Replay Theater)와 '말로 만들기'를 연습용 폴더에서 저희가 직접 돌려 확인했어요. 명령은 공식 문서·공식 샘플 README 그대로예요. mod는 샌드박스 없이 내 컴퓨터 권한으로 돌아가니 맨 아래 '꼭 알고 쓰기'를 먼저 읽어 주세요.

준비물

  • 클로드 코드 2.1.287 이상 — 터미널에 claude --version
  • git — 공식 샘플을 받을 때
  • 터미널(윈도우 터미널·맥 터미널 등)이나 데스크톱 앱 Code 탭 — mod 화면은 여기서 보여요. claude -p와 클라우드 세션에선 그려지지 않아요

사용 방법

1

공식 샘플 받기

터미널에서 아래 '복사해서 쓰기'의 ① 두 줄을 그대로 실행하세요. 앤트로픽이 공유한 샘플 mod 3개가 든 폴더로 들어가요. 공식 README는 '지원 없이 있는 그대로 공유'라고 적어요(Apache-2.0).

2

깔기 전에 하는 일 목록 보기

claude plugin validate ./blast-radius 처럼 폴더 이름을 넣어 실행하면, mod를 돌리지 않고 어떤 순간에 끼어드는지(hooks)와 무엇을 하는지(calls)가 나와요. $.process.run은 프로그램 실행, 네트워크·파일 쓰기 같은 줄이 있으면 그 mod 코드를 먼저 읽어 보세요.

3

한 번만 붙여 보기 — Blast Radius

claude --plugin-dir ./blast-radius 로 클로드 코드를 열어요. 클로드가 rm -rf·git reset --hard·git push --force 같은 명령을 실행하려 하면 멈추고, 지울 파일 수와 크기를 입력창 위에 보여 줘요. 창이 뜨면 Ctrl+X 다음 Tab으로 그 창에 들어간 뒤 1(진행) 또는 2(취소)를 누르세요(그냥 숫자를 치면 입력창에 들어가요 — 저희 확인). 저희가 '확인 없이 바로 rm -rf build'라고 시켰을 때 지울 파일 8개(약 537KB)가 떴고, 취소하자 클로드가 '지우지 않았습니다'라고 답했어요.

4

대화량 날씨 — Token Weather

claude --plugin-dir ./token-weather 로 열면 입력창 위에 대화 창이 얼마나 찼는지가 날씨로 떠요. 25% 아래 ☀ 맑음, 25~49% ☁ 흐림, 50~74% ☂ 비, 75~89% ☇ 폭풍, 90% 넘으면 ↯ 곧 정리(Compact soon). 저희가 큰 문서를 읽힐수록 맑음 0% → 흐림 43% → 폭풍 79% → 곧 정리 90%로 바뀌었어요. 대화 창이 100만 토큰인 모델은 천천히 차서 한참 맑음으로 보여요.

5

방금 고친 곳 다시 보기 — Replay Theater

claude --plugin-dir ./replay-theater 로 열고 일을 시킨 뒤 /replay 를 치면, 방금 차례에서 고친 곳을 한 단계씩 빨강·초록으로 보여 줘요. n(다음)·p(이전)·c(닫기). 고치는 일 자체는 막거나 바꾸지 않고 보기만 해요.

6

계속 쓰기 — 설치

샘플 폴더에서 '복사해서 쓰기'의 ③ 두 줄을 실행하면 모든 창에서 켜져요(이 폴더를 지우거나 옮기면 다시 안 떠요). 셋 다 쓰려면 install 줄의 이름만 blast-radius·replay-theater로 바꿔 한 번씩. 클로드 코드가 열려 있었다면 /reload-plugins.

7

필요한 건 말로 만들기

클로드 코드 입력창에 원하는 화면을 말로 부탁하면, 클로드가 내장 'plugin-authoring' 스킬로 mod를 직접 만들어요. 다 만들면 'Enable hot reloading for this session?'이 뜨는데 2번 'Enable for this session'을 고르면 그 차례가 끝날 때 바로 붙어요. 저희가 아래 ④ 문장을 넣었더니 약 30초 만에 만들어졌고, 띠에 '읽은 파일 3개 · 고친 파일 1개 · 실행한 명령 1개'가 떴어요. 이렇게 만든 mod는 그 세션에서만 살아요 — 계속 쓰려면 클로드가 알려 준 폴더를 다른 곳에 복사해 두고 claude --plugin-dir <그 폴더>로 여세요.

8

잘 붙었는지 보기·끄기

입력창에 /plugin 을 치면 탭 아래 흐린 줄에 '1 mod active · 이름'처럼 지금 켜진 mod가 나와요. 하나만 끄려면 /plugin → Installed 탭에서 끄거나 지우기. 이번 한 번만 전부 끄려면 claude --safe-mode 로 열기(다른 개인 설정도 같이 꺼져요). 늘 끄려면 ~/.claude/settings.json에 "disableAllHooks": true(내 설정 훅·상태 줄도 같이 멈춰요).

복사해서 쓰기

① 공식 샘플 받기

터미널

git clone https://github.com/anthropics/claude-code-playground.git
cd claude-code-playground/claude-code/mods

② 깔기 전 확인 + 한 번만 붙여 보기

①의 폴더에서

claude plugin validate ./blast-radius
claude --plugin-dir ./blast-radius --plugin-dir ./token-weather --plugin-dir ./replay-theater

③ 계속 쓰기(설치)

①의 폴더에서 — 이름만 바꿔 셋 다

claude plugin marketplace add ./
claude plugin install token-weather@claude-code-playground-mods --scope user

④ 말로 만들기 — 저희가 넣은 요청 문장

클로드 코드 입력창. 띠에 넣고 싶은 내용만 바꿔 쓰세요

mod 하나 만들어 줘: 입력창 위 띠에 한 줄로, 이번 대화에서 클로드가 읽은 파일 수, 고친 파일 수, 실행한 명령 수를 한글로 보여 줘. 테스트 파일은 만들지 말고 validate만 해 줘.

⑤ 끄기

필요할 때

/plugin
claude --safe-mode

막힐 때

  • 띠·창이 안 보여요
    claude --version이 2.1.287 이상인지, /plugin 흐린 줄에 mod 이름이 있는지 보세요. claude -p와 클라우드 세션에선 그려지지 않아요. VS Code 확장은 2.1.299 이상에서 그려요.
  • Blast Radius 버튼이 안 눌려요
    창이 입력창 위에 떠 있을 땐 키가 입력창으로 가요. Ctrl+X 다음 Tab으로 창에 들어가서 1·2를 누르세요. 저희도 그냥 2를 쳤더니 입력창에 '2'가 써졌어요.
  • 날씨가 계속 맑음이에요
    대화 창이 큰 모델(100만 토큰)은 아주 많이 읽어야 바뀌어요. 정상이에요.
  • 말로 만든 mod가 다음 날 없어요
    핫 리로드로 붙인 mod는 그 세션 한정이에요. 클로드가 알려 준 폴더를 복사해 두고 --plugin-dir로 여세요.

꼭 알고 쓰기

  • 공식 문서 원문: "A mod is code that runs with your permissions. It can read and write your files, start processes, and make network requests." — mod는 내 파일 읽기·쓰기, 프로그램 실행, 인터넷 접속을 할 수 있어요.
  • "Mods aren't sandboxed." — /sandbox를 켜도 mod가 띄운 프로그램은 그 밖에서 돌아요. 내가 보내는 질문과 클로드가 쓰는 도구도 전부 볼 수 있고, 묻기 전에 대신 승인할 수도 있어요.
  • 믿을 수 있는 사람·마켓 것만 깔고, 깔기 전에 claude plugin validate로 하는 일 목록을 보세요. 업데이트 뒤에도 다시 보세요.
  • Blast Radius는 안전망이지 권한 설정이 아니에요(공식 안내 "a safety net, not a permission system"). 명령 글자만 읽어서 스크립트 안에서 부르는 rm 같은 건 못 잡아요. 꼭 막아야 할 건 권한 설정(/permissions)으로.
  • 공개 mod 목록: github.com/karanb192/awesome-claude-code-mods — 각 mod가 무엇에 접근하는지 스캔해 둔 목록이에요(공식 목록 아님).
