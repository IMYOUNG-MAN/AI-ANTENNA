founder-skill 설치하고 쓰는 법

Claude Code에 창업 검증 스킬 11개를 붙이면, 아이디어 하나로 이사회 평가 → 경쟁사 조사 → 고객 100명 패널 → 가격 → 재무 → 마케팅 → 사업계획서까지 차례로 만들어 줘요. 무료 오픈소스(MIT)이고 가입·API 키가 필요 없어요.

준비물

  • Claude Code (Claude 요금제 필요)
  • Python 3.8 이상 (재무·고객 패널 계산 도구가 써요)
  • 무료 오픈소스 · MIT

사용 방법

1

설치

Claude Code 입력창에 아래 '설치 두 줄'을 한 줄씩 넣으세요. 또는 Claude에 저장소 주소를 붙여 넣고 'install skill'이라고 해도 돼요.

2

이사회부터 열기

'/founder-skill:founder-board' 뒤에 아이디어를 한 문장으로 쓰세요(무엇을, 얼마에, 누구에게, 창업비). 이사 세 명이 각자 다른 원칙으로 점수를 매기고 투자·조건부 투자·패스로 투표해요. 결과는 프로젝트의 founder/board.md에 저장돼요.

3

순서대로 이어 가기

board → competitors → consumer → pricing → offer → cfo → marketing → brand → ops → launch → plan 순서로 돌리면 앞 결과를 읽고 이어서 만들어요. 마지막 /founder-plan이 사업계획서와 판정(흑자·아직·정보 부족)을 숫자로 내요.

4

고객 패널은 가볍게 먼저

고객 100명 패널은 클로드가 많이 일해서 사용량이 커요. 처음엔 '--quick'(20명)으로 돌려 보세요.

복사해서 쓰기

설치 두 줄

Claude Code 입력창에 한 줄씩

/plugin marketplace add Jakeschincariol/founder-skill
/plugin install founder-skill@founder-skill

이사회 (영상에서 쓴 요청)

아이디어만 바꿔서

/founder-skill:founder-board 성수동에 말차 카페를 열려고 해. 아이스 말차라떼 한 잔 6,500원, 출근하는 20~30대 직장인 대상, 창업 비용 8천만 원. 질문하지 말고 바로 이사회 평가해 줘. 답과 파일은 한국어로.

고객 패널 빠르게

살지 말지 먼저 보기

/founder-skill:founder-consumer --quick

재무 계산

손익분기·1년 수익

/founder-skill:founder-cfo

사업계획서로 묶기

마지막에

/founder-skill:founder-plan

막힐 때

  • 명령어가 안 보여요
    플러그인으로 설치하면 이름 앞에 'founder-skill:'이 붙어요. '/founder-skill:founder-board'처럼 치세요. 그냥 '/founder-board'로 쓰고 싶으면 README대로 skills 폴더를 ~/.claude/skills에 복사하세요.
  • 파일 쓰기 허락을 계속 물어봐요
    스킬이 founder/ 폴더에 여러 파일을 써요. 물어볼 때마다 허락하거나, 새 폴더를 만들어 그 안에서 실행하세요.

주의할 점

  • 이사회는 책 속 사업 원칙을 적용하는 것이고 실제 인물이 아니에요. 고객 패널도 시뮬레이션이라 실제 수요는 작은 테스트로 꼭 확인하세요.
  • 여러 클로드가 동시에 일하는 기능(이사회·고객 패널)은 사용량이 많아요.
