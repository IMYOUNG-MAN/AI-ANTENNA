챗GPT Intelligent UI 써보기 — 답을 버튼·차트·계산기로 받는 법

GPT-6이 내 계정에 들어왔는지 확인하고, 숫자를 바꾸면 결과가 바로 바뀌는 계산기와 비교표를 대화창 안에서 직접 만들어 봅니다.

준비물

  • 챗GPT 계정 (무료도 됩니다)
  • 웹 브라우저(chatgpt.com) 또는 최신 버전 앱. 오래된 PC용 앱은 지원하지 않아요
  • 5분

순서

1

내 계정에 GPT-6이 들어왔는지 확인

10월 7일 Plus·Pro·Business·Enterprise부터, 10월 8일부터 무료·Go 요금제로 순차 배포되고 있어요. 유료 요금제는 GPT-6 Sol, 무료·Go는 GPT-6 Luna가 들어가고, 두 쪽 모두 Intelligent UI를 쓸 수 있어요. 따로 켜는 스위치는 없고, 순서가 돌아오면 Chat 탭에서 바로 동작합니다.

✓ Chat 탭 모델 메뉴에 GPT-6이 보인다.

2

그냥 물어보기 — 화면으로 답할지는 챗GPT가 정해요

평소처럼 질문하면 챗GPT가 필요할 때 다이어그램·차트·지도·버튼을 섞어 답해요. 모든 답이 화면으로 나오지는 않고, 글로만 답하는 경우도 많아요. 생각 수준은 Instant부터 Extra High까지 다 되지만, Pro 수준(GPT-6 Astra)에서는 Intelligent UI가 나오지 않아요.

제주도 2박 3일 동선을 지도로 보여줘

✓ 답 안에 지도나 카드처럼 누를 수 있는 화면이 섞여 나온다.

3

원하는 형태를 직접 말하기 — 계산기 만들기

'옆으로 비교해 줘', '계산기를 만들어 줘'처럼 형태를 직접 말하면 더 잘 나와요. 공식 소개에도 더치페이 계산기, 저축 계산기, 대화 안에서 하는 간단한 게임이 예로 나와요. 숫자 칸을 바꿨을 때 결과가 같이 바뀌는지 꼭 눌러 보세요.

이 대화 안에서 더치페이 계산기를 만들어 줘. 총액, 인원수, 팁 % 칸을 고칠 수 있게 하고, 숫자를 바꾸면 1인당 금액이 바로 바뀌게 해 줘. 계산식도 보이게 해 줘.

✓ 인원수를 바꾸면 1인당 금액이 바로 다시 계산된다.

4

비교표 받기

물건이나 요금제를 고를 때 나란히 놓고 보는 화면으로 받을 수 있어요. 다만 챗GPT가 모르는 사양을 채워 주지는 않으니, 가격·사양처럼 중요한 숫자는 공식 페이지에서 한 번 더 확인하세요.

아이폰 17, 갤럭시 S26, 픽셀 10을 옆으로 나란히 비교해 줘. 가격, 무게, 배터리, 카메라 항목으로.

✓ 세 제품이 열로 나란히 놓인 비교 화면이 나온다.

5

화면이 너무 많으면 줄이기

그림이 많은 답이 불편하면 웹 설정에서 'Layout and visuals'를 끄면 돼요. 끈 뒤에도 일부 그림은 나올 수 있어요.

✓ 설정을 끈 뒤 같은 질문에 글 위주로 답이 온다.

여기서 막힙니다

화면 없이 글로만 답해요

아직 내 계정 순서가 안 왔을 수 있어요. 모델 메뉴에서 GPT-6인지, 생각 수준이 Pro가 아닌지 확인하고, '계산기로 만들어 줘'처럼 형태를 직접 말해 보세요.

PC 앱에서는 안 나와요

오래된 윈도우·맥 앱은 지원하지 않아요. 앱을 최신으로 업데이트하거나 웹(chatgpt.com)에서 써 보세요.

Work·Codex 탭에서는 안 돼요

GPT-6은 Chat 탭에만 들어갔어요. Work와 Codex 모델은 그대로예요.

계산기 결과가 이상해요

'계산식도 보이게 해 줘'를 붙여 식을 직접 확인하세요. 실제 결제·예약 금액은 따로 계산해 보는 게 안전해요.

바꿔볼 것

  • '레시피를 4인분으로 바꾸는 화면 만들어 줘' — 인원수에 따라 재료 양이 바뀌는 레시피
  • '월 30만 원씩 모으면 5년 뒤 얼마인지 계산기로' — 금리·기간을 바꿔 보는 저축 계산기
