rhwp — 한컴 없이 한글 파일 열고 고치기

HWP·HWPX 파일을 크롬·엣지에서 바로 열고, 고치고, 저장해요. 설치·회원가입 없이 무료예요.

준비물

  • 크롬·엣지·파이어폭스 중 하나 (PC 추천)
  • 열고 싶은 한글 파일 (.hwp 또는 .hwpx)

사용 방법

1

edwardkim.github.io/rhwp 에 들어간다

설치 없이 바로 쓰는 온라인 편집기예요. 처음 들어가면 화면 스킨을 고르는 창이 떠요 — 마음에 드는 걸 고르고 '시작하기'를 누르세요.

2

한글 파일을 연다

파일 메뉴 → 열기를 누르고 파일을 고르세요. 저희가 35쪽짜리 공문서를 열어 보니 1초도 안 걸렸어요.

3

글자를 고친다

한컴오피스처럼 원하는 곳을 눌러 바로 입력하면 돼요. 위쪽 도구 막대에 글꼴·크기·정렬·표·그림 버튼이 있어요.

4

저장한다

파일 메뉴에서 고르세요. '저장'은 원래 형식 그대로, 'HWP 형식으로 저장'·'HWPX 형식으로 저장'은 형식을 골라서, 'PDF로 저장'은 PDF로 바꿔서 저장해요. 'Word 문서(.doc)로 내보내기'도 있어요.

5

자주 쓴다면 브라우저 확장으로 설치한다

크롬 웹스토어에서 'rhwp'를 검색해 'Chrome에 추가'를 누르세요(사용자 10만 명, 평점 4.9). 엣지는 Edge 추가 기능, 파이어폭스는 부가 기능에서 같은 이름으로 찾으면 돼요.

막힐 때

  • 글꼴이 원본과 조금 달라 보여요
    내 컴퓨터에 없는 글꼴은 비슷한 글꼴로 바꿔 보여 줘요. 내용은 그대로예요.
  • 복잡한 문서 일부가 어긋나요
    아직 개발 중(v0.8)인 프로젝트라 아주 복잡한 표·도형은 다르게 보일 수 있어요. 중요한 제출 서류는 저장 후 한 번 더 확인하세요.
  • 저장을 누르면 저장 위치를 물어봐요
    브라우저가 파일을 어디에 둘지 묻는 거예요. 폴더를 고르고 저장하면 돼요.
