Docling으로 PDF 표를 칸 그대로 엑셀에 옮기는 법

PDF 표를 복사해 붙이면 한 칸에 다 뭉치죠. Docling(IBM이 만든 무료 오픈소스 AI)으로 PDF를 바꾸면, 표가 줄과 칸이 나뉜 그대로 나와서 복사해 붙이면 엑셀에 칸 그대로 들어가요.

준비물

  • 윈도우·맥 PC
  • Python 3.10 이상 (python.org에서 무료)
  • 처음 한 번 AI 모델 내려받기(약 1~2분)

사용 방법

1

Python 설치

python.org/downloads에서 'Download Python'을 눌러 설치하세요. 설치 첫 화면 아래 'Add python.exe to PATH'에 꼭 체크하세요.

2

Docling 설치

시작 버튼에서 'cmd'를 검색해 명령 프롬프트를 열고 아래 '설치' 줄을 붙여 넣으세요. 몇 분 걸려요.

3

PDF 변환

PDF가 있는 폴더에서 명령 프롬프트를 열고(폴더 주소창에 cmd 입력 후 Enter) 아래 '변환' 줄의 파일 이름만 바꿔 넣으세요. 같은 폴더에 같은 이름의 .html 파일이 생겨요.

4

엑셀로 옮기기

생긴 .html 파일을 더블클릭해 브라우저로 열고, 표를 마우스로 드래그해 복사(Ctrl+C) → 엑셀에 붙여넣기(Ctrl+V) 하면 칸 그대로 들어가요. 엑셀에서 '파일 → 열기'로 .html을 바로 열어도 돼요.

복사해서 쓰기

설치

명령 프롬프트에 한 줄

pip install docling

변환

파일 이름만 바꿔서

docling convert 내파일.pdf --to html --no-ocr

폴더 안 PDF 전부

여러 개 한 번에

docling convert . --to html --no-ocr

막힐 때

  • 'docling'은(는) 내부 또는 외부 명령이 아닙니다
    Python 설치 때 'Add python.exe to PATH'를 체크하지 않았을 때 생겨요. Python을 다시 설치하며 체크하거나, 명령 앞에 'python -m'을 붙여 'python -m docling.cli.main convert …'로 실행하세요.
  • 아주 오래 걸려요
    '--no-ocr'을 빼면 글자 인식까지 돌려서 몇 분~수십 분 걸려요. 글자가 살아 있는 PDF는 꼭 '--no-ocr'을 붙이세요.
  • 스캔한 PDF는 한글이 깨져요
    기본 글자 인식 엔진이 한국어를 잘 못 읽어요. 이 방법은 파일로 받은 PDF(명세서·견적서 등)에 쓰세요.

주의할 점

  • 모든 처리는 내 PC 안에서 해요. 다만 처음 한 번 AI 모델을 내려받느라 인터넷이 필요해요.
  • 변환 결과는 원본과 꼭 한 번 대조하세요. 칸이 합쳐진 복잡한 표는 가끔 어긋날 수 있어요.
