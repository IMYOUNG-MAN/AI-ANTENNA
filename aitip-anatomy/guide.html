anatomy 스킬로 '움직이는 설명 그림' 만들기

어려운 원리를 물어보면, Claude Code가 실제로 움직이는 기계 그림(HTML)으로 설명해 줘요. 마우스를 올리면 분해되고, 버튼을 누르면 값이 바뀌어요. 발표·교육 자료에 바로 쓸 수 있어요.

준비물

  • Claude Code (Codex · OpenCode도 가능)
  • Node.js 20.10 이상
  • 무료 · 오픈소스 (MIT) · API 키 필요 없음

사용 방법

1

설치 (한 줄)

터미널에 아래 '설치 명령'을 넣으세요. Codex는 끝의 claude-code를 codex로 바꾸면 돼요.

2

요청하기

Claude Code에서 '/anatomy'로 시작해서 설명하고 싶은 원리를 적으세요. '인터랙티브로'를 붙이면 마우스·버튼으로 움직이는 그림이 나와요.

3

기다리기

부품을 하나하나 그리고 직접 확인까지 해서 10~15분쯤 걸려요. 저희 에스프레소 머신은 15분 걸렸어요.

4

열어 보기

만들어진 .html 파일을 브라우저로 열면 돼요. 발표 화면에 그대로 띄우거나 화면 녹화해서 쓸 수 있어요.

복사해서 쓰기

설치 명령

터미널

npx skills add wheresryan22/anatomy -g -a claude-code

영상에서 넣은 요청

Claude Code

/anatomy 에스프레소 머신이 커피를 내리는 원리를 설명해 줘. 인터랙티브로

업무·개발 설명

발표 자료

/anatomy 우리 서비스에서 주문이 들어와 배송까지 가는 흐름을 공장 설비처럼 설명해 줘. 인터랙티브로

수업 자료

교육

/anatomy 심장이 피를 뿜어내는 원리를 펌프 기계처럼 설명해 줘. 인터랙티브로

막힐 때

  • /anatomy가 이상한 경로로 바뀌어요
    윈도우 Git Bash에서 Claude Code를 실행하면 '/anatomy'가 'C:/Program Files/Git/anatomy'처럼 바뀔 수 있어요. PowerShell이나 명령 프롬프트에서 실행하세요.
  • 너무 오래 걸려요
    정상이에요. 그림이 복잡할수록 오래 걸려요. 처음엔 '간단하게'를 붙여서 시험해 보세요.

더 잘 나오게

  • 만든 그림은 HTML이라 노션·블로그에 임베드하거나 화면 녹화해서 영상으로 쓸 수 있어요.
