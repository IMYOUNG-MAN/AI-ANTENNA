God's Eye View 설치법 + 꼭 봐야 할 장면

지금 하늘에 떠 있는 비행기, 인공위성, 지진, 산불 같은 공개 데이터를 3D 지구본 하나에서 봐요. 저희가 켜 보니 전 세계 항공편 1만 3천여 대가 실시간으로 잡혔어요. API 키 없이 시작돼요.

준비물

  • 윈도우·맥·리눅스 컴퓨터 (폰은 안 돼요)
  • 무료 · MIT 오픈소스. 음성 대화와 실사 3D 건물만 유료 키가 필요해요

사용 방법

1

쉬운 방법: Pinokio로 설치 (공식 안내)

Pinokio(desktop.pinokio.co)를 8.2 이상으로 설치 → 앱 목록에서 God's Eye View → Install → Start. 공식 안내 방법이고, 저희는 아래 터미널 방법으로 확인했어요.

2

터미널 방법 (저희가 해 본 방법)

Node.js 24를 설치한 뒤 터미널에서 git clone https://github.com/bilawalsidhu/gods-eye-view.git → cd gods-eye-view → npm ci → npm run dev. 브라우저에서 http://localhost:4173 을 열면 돼요.

3

첫 화면에서 'Explore Manually'

처음 뜨는 'Choose your first view'에서 Explore Manually를 고르면 깨끗한 지구본에서 시작해요. 기본 위치는 미국 오스틴이에요.

4

왼쪽 DATA LAYERS에서 보고 싶은 것만 켜기

DATA LAYERS의 + 를 누르고 Live Flights(항공편), Satellites(인공위성), Earthquakes(지진), Active Fires(산불) 옆 OFF를 눌러 켜세요. 켜면 옆에 개수가 떠요(항공편은 저희 때 13.5K).

5

아래 VISUAL PRESETS로 화면 바꾸기

NVG(야간투시), FLIR(열화상), CRT(옛날 모니터), Noir(흑백), Snow 중 고르면 바로 바뀌어요. Normal을 누르면 원래대로예요.

6

마우스 휠로 지구 전체 ↔ 도시

휠을 내리면 지구 전체로 빠지고, 올리면 다시 내려가요. 아래 LOCATION에서 뉴욕·도쿄·런던 같은 도시로 바로 이동할 수 있어요.

꼭 봐야 할 장면

전 세계 항공편

Live Flights만 켜고 휠로 지구 전체까지 빠져 보세요

DATA LAYERS → Live Flights ON → 휠 아래로

영화 속 정찰위성 화면

도시 위에서 야간투시·열화상으로 바꿔 보세요

VISUAL PRESETS → NVG / FLIR

지구를 감싼 인공위성

Satellites를 켜고 지구 전체로

DATA LAYERS → Satellites ON

조종석 시점

추적 중인 비행기가 있을 때 오른쪽 CONTEXT 패널의 COCKPIT

CONTEXT → COCKPIT

막힐 때

  • 도시 화면에서 비행기가 잘 안 보여요
    도시를 낮게 보고 있으면 비행기가 화면 위쪽 하늘에만 표시돼요. 휠로 위로 조금 빠지면 잘 보여요.
  • 밤인 도시는 어둡거나 초록색으로만 나와요
    지금 밤인 곳은 어둡게 보일 수 있어요(저희가 밤 시간 도쿄를 열었을 때 그랬어요). 낮인 도시로 옮겨 보세요.
  • 실사 3D 건물이 안 나와요
    실사 3D는 오른쪽 아래 POWER UP에서 Cesium 토큰(개인 비상업 무료)이나 구글 지도 키(사용량 과금)를 넣어야 나와요. 키가 없어도 위성 사진 지구본은 그대로 돼요.
  • 음성으로 말 걸기가 안 돼요
    음성 대화는 OpenAI 키가 필요한 유료 기능이에요.

더 잘 나오게

  • 누구나 볼 수 있는 공개 데이터(항공기 신호, 위성 궤도, 미국 지질조사국 지진 정보 등)를 모아 보여 주는 시각화예요. 감시 도구가 아니에요.
  • 군용기·군사시설 레이어도 있지만, 한국에서는 군사시설 위치를 찍어 공유하면 법에 걸릴 수 있으니 켜지 않는 걸 권해요.
