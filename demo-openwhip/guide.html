OpenWhip 설치법 (Claude 채찍 앱)

Claude Code 같은 AI 코딩 도구가 느릴 때, 화면에 채찍을 꺼내 휘두르면 작업을 끊고 재촉 메시지를 보내요. 장난 앱이에요.

준비물

  • 윈도우 또는 맥 (리눅스는 아래 추가 설치)
  • Node.js (npm 명령어를 쓰려면 필요해요 — nodejs.org에서 LTS 버전 설치)
  • 터미널에서 쓰는 AI 코딩 도구 (Claude Code, Codex 등)
  • 무료 공개 (GitHub)

사용 방법

1

Node.js 설치 (없을 때만)

nodejs.org에서 LTS 버전을 받아 설치하세요. 설치 뒤 터미널(윈도우는 PowerShell)을 새로 열어야 npm 명령어가 돼요.

2

OpenWhip 설치

터미널에 아래 명령어를 붙여 넣고 Enter를 누르세요.

3

켜기

터미널에 openwhip 을 치면 화면 구석(트레이)에 아이콘이 생겨요.

4

채찍 꺼내기

트레이 아이콘을 누르면 채찍이 나와요. 마우스로 휘두르면 돼요. 한 번 클릭하면 채찍을 내려놔요.

5

무슨 일이 일어나나

휘두를 때마다 AI 코딩 도구에 Ctrl+C(작업 중단)를 보내고, 재촉 메시지 5개 중 하나를 대신 입력해요.

복사해서 쓰기

설치

터미널에 붙여 넣기

npm install -g openwhip

실행

설치 뒤

openwhip

리눅스 추가 설치

리눅스만

sudo apt install xdotool

막힐 때

  • npm을 찾을 수 없대요
    Node.js가 없거나, 설치 뒤 터미널을 새로 열지 않았어요. nodejs.org에서 설치하고 터미널을 껐다 켜세요.
  • 진짜로 작업이 멈췄어요
    채찍질하면 실제로 Ctrl+C를 보내서 하던 작업이 끊겨요. 중요한 작업 중엔 쓰지 마세요.
  • 저장소에 코인 주소가 있어요
    만든 사람이 장난으로 올린 토큰 홍보예요. 앱 기능과는 아무 관계가 없으니 사지 마세요.
