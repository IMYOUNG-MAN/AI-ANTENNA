OpenShorts — 긴 영상을 세로 쇼츠로 잘라 주는 무료 프로그램

공식 설치 문서 기준. 긴 영상을 넣으면 볼 만한 구간을 3~15개 골라, 말하는 사람 얼굴을 따라 세로로 자르고 자막까지 박아 줘요. 내 PC에 직접 깔면 무료(MIT)이고 워터마크·분량 제한이 없어요. 클로드 코드에 연결하면 말 한 줄로 시킬 수 있어요.

준비물

  • Docker Desktop — 윈도우는 WSL2 백엔드로 깔아요
  • 램 8GB 이상인 PC(그래픽카드 없어도 돼요. CPU만이면 8분 영상에 5~8분쯤)
  • Gemini API 키 — aistudio.google.com에서 무료로 발급(무료 한도 안에서 써요)
  • 클로드 코드로 시키려면 Claude Code(클로드 유료 요금제)
  • 자를 영상은 내 영상이나 허락받은 영상만

사용 방법

1

① 받기 — 터미널에 두 줄

아래 '복사해서 쓰기'의 받기 1·2를 차례로 넣어요. 저장소를 내 PC로 내려받고 그 폴더로 들어가요.

2

② 켜기 — Docker로 실행

Docker Desktop을 켜 둔 채 '켜기'를 넣어요. 처음엔 모델을 내려받느라 오래 걸려요. 끝나면 브라우저에서 localhost:5175를 열어요.

3

③ 키 넣기

대시보드 Settings에 Gemini 키를 붙여 넣어요. 쇼츠 자르기엔 Gemini 키 하나면 돼요. fal.ai·ElevenLabs·Upload-Post 키는 AI 광고 영상·더빙·자동 게시를 쓸 때만 필요해요.

4

④ 영상 넣기

Clip Generator에 긴 영상(팟캐스트·강의·인터뷰·라이브)을 올려요. 말이 많은 영상일수록 잘 골라요.

5

⑤ 결과 보기

구간마다 15~60초짜리 세로 쇼츠가 나와요. 한 사람이면 얼굴을 따라 자르고, 두 사람이면 위아래로 쌓고 자막을 가운데 이음새에 넣어요. 화면 녹화 영상은 화면 위·발표자 아래로 놓아요. 배치는 AI가 영상마다 골라요. 첫 줄 문구(훅)도 자동으로 붙어요.

6

⑥ 클로드 코드로 시키기

OpenShorts가 켜져 있는 동안 터미널에 '클로드 코드 연결'을 한 번 넣어요. 그다음 클로드 코드에 '이 영상 쇼츠로 잘라 줘'처럼 말하면 process_video로 자르고, list_clips로 결과를 보여 줘요. 내 PC가 꺼져 있으면 안 돼요.

7

⑦ 다시 자르기·자막만

마음에 안 드는 구간은 recut_clip으로 다시 자르고, 자막이 이미 있는 영상은 captions:false, 첫 줄 문구를 빼려면 auto_hook:false로 시켜요.

복사해서 쓰기

받기 1

터미널

git clone https://github.com/mutonby/openshorts.git

받기 2

터미널

cd openshorts

켜기

Docker Desktop을 켠 뒤, openshorts 폴더에서

docker compose up --build

클로드 코드 연결

OpenShorts가 켜져 있을 때, 터미널에 한 번

claude mcp add --transport http openshorts http://localhost:8000/mcp

시키기

클로드 코드 입력칸, 파일 경로는 내 것으로

C:\영상\팟캐스트.mp4 이 영상 쇼츠로 잘라 줘. 제일 좋은 3개만 보여 줘.

막힐 때

  • 켜기가 한참 안 끝나요
    처음엔 받아쓰기·얼굴 인식 모델을 내려받아요. 램이 8GB보다 작으면 멈출 수 있어요.
  • Gemini 키 없이 쓰고 싶어요
    .env에 LLM_BASE_URL로 Ollama 같은 내 PC 모델을 지정하면 구간 고르기는 내 모델로 해요. 화면 배치 자동 고르기와 말 없는 영상은 Gemini가 있어야 해요(공식 README).
  • 클로드 코드가 OpenShorts를 못 찾아요
    OpenShorts(Docker)가 켜져 있어야 해요. claude mcp list로 openshorts가 보이는지 확인하세요.
  • 한국어 영상도 되나요?
    README에 한국어는 따로 적혀 있지 않아요. 받아쓰기(faster-whisper)는 영상 언어를 스스로 알아내는 방식이에요. 내 영상 하나로 먼저 확인해 보세요.
