파일 끌다가 키 하나로 변환하는 법 — DragShift · Filee

무료 오픈소스 두 개를 깔면, 파일을 사이트에 올리지 않고 끌다가 키 하나만 눌러서 바꿀 수 있어요. DragShift는 Shift, Filee는 Ctrl이라 둘 다 깔아도 안 부딪혀요. 결과는 원본 옆에 새 파일로 생기고 원본은 그대로예요.

준비물

  • 윈도우 10·11 (DragShift는 맥·리눅스도 돼요. Filee 맥·리눅스판은 미리보기)
  • 관리자 권한 필요 없어요
  • 무료 · 오픈소스(MIT) · 인터넷에 올리지 않고 내 컴퓨터에서 처리

사용 방법

1

DragShift 설치

아래 'DragShift 받기' 주소에서 DragShift-Setup.exe를 받아 실행하세요(내 계정에만 설치, 관리자 권한 없이 돼요). 설치 없이 쓰려면 DragShift.exe만 받아 실행해도 돼요. 실행하면 작업 표시줄 오른쪽 아이콘 칸에 들어가 있어요. 맥은 아래 '맥 설치' 한 줄을 터미널에 붙여 넣으세요.

2

DragShift — 끌다가 Shift

탐색기나 바탕화면에서 파일을 끌기 시작한 다음 Shift를 한 번 누르세요. 커서 아래에 원형 메뉴가 떠요. 원하는 형식(PNG·PDF·HEIC 등) 위에 놓으면 끝이에요. Shift를 한 번 더 누르면 압축·크기 바꾸기·자르기·합치기 같은 '도구' 쪽으로 바뀌어요.

3

PDF 여러 개 합치기

합칠 PDF를 모두 고른 다음(첫 파일 클릭 → Shift 누른 채 마지막 파일 클릭) 그중 하나를 끌다가 Shift 두 번 → MERGE에 놓으세요. 끝나면 오른쪽 아래 알림에 쪽수와 용량이 나오고, 잘못했으면 'Undo'로 되돌릴 수 있어요.

4

Filee 설치

아래 'Filee 받기' 주소에서 Filee-버전-win-Setup.exe를 받아 실행하세요. 설치 없이 쓰려면 win-Portable.zip을 풀고 Filee.exe를 실행하면 돼요. 처음에 '변환 엔진 선택' 창이 뜨는데, 문서·사진·HWP는 엔진 없이 되니 그냥 넘어가도 돼요.

5

Filee — Ctrl 누르고 끌기

Ctrl을 먼저 누른 채로 파일을 끌기 시작하세요(맥은 Option). 그 자리에 형식 도넛이 열리고, 끌고 있는 파일에 맞는 형식만 보여요. PDF 위에 놓으면 진행률이 돌고 원본 옆에 PDF가 생겨요. 도넛이 열린 상태에서 Tab이나 마우스 휠을 돌리면 덜 쓰는 형식이 나와요.

막힐 때

  • 처음 실행할 때 'Windows의 PC 보호' 창이 떠요
    두 앱 모두 아직 코드 서명 전이라 그래요. '추가 정보' → '실행'을 누르면 돼요. 코드는 깃허브에 다 공개돼 있어요.
  • Shift(또는 Ctrl)를 눌러도 메뉴가 안 떠요
    앱이 켜져 있는지 작업 표시줄 오른쪽 아이콘 칸에서 확인하세요. 파일을 '끌고 있는 중'에 눌러야 해요. Filee는 Ctrl을 먼저 누른 채로 끌기 시작해야 해요.
  • DragShift에서 도구(압축·합치기)가 안 보여요
    메뉴가 뜬 상태에서 마우스를 살짝 움직인 뒤 Shift를 한 번 더 누르세요. 변환 ↔ 도구가 바뀌어요.
  • Filee에서 동영상·음악 변환이 안 보여요
    동영상·오디오는 FFmpeg 엔진이 있어야 해요. Filee 설정 → 변환 엔진에서 FFmpeg를 받으세요(필요할 때만).

알아 두면 좋은 것

  • 둘 다 결과를 원본 옆에 새 파일로 만들어요. 원본은 바뀌지 않아요.
  • DragShift는 사진 크기 바꾸기·자르기·모자이크(Redact)·위치 정보 지우기(Metadata)도 돼요. 사진 올리기 전에 위치 정보 지울 때 좋아요.
  • Filee는 브라우저에서 사진을 끌어 와도 바로 변환돼요. 폴더를 지정해 두면 들어오는 파일을 자동으로 바꾸는 '자동 변환 폴더'도 있어요.
  • DragShift 설정에서 누르는 키를 Shift·Ctrl·Alt 중에 바꿀 수 있어요. 두 앱을 같이 쓸 땐 기본값(Shift·Ctrl) 그대로 두세요.
