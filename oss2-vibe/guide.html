Vibe 설치법 + 한국어 설정

회의·강의 녹음 파일을 내 컴퓨터 안에서 한국어 글로 받아써요. 인터넷에 올리지 않고, 월 한도도 없어요.

준비물

  • 윈도우 PC (맥판도 같은 페이지에 있어요)
  • 처음 한 번 받아쓰기 모델 내려받기(약 1.6GB)
  • 무료 · MIT 오픈소스

사용 방법

1

GitHub에서 받기

github.com/thewh1teagle/vibe → 오른쪽 Releases → 윈도우는 'vibe_x.x.x_x64-setup.exe'를 받아 설치하세요.

2

처음 켜면 모델이 자동으로 받아져요

'Downloading Model...' 화면이 뜨고 한 번만 받아요. 인터넷이 필요한 건 이때뿐이에요.

3

화면을 한국어로

왼쪽 아래 Settings(설정) → General(일반) → Display language(표시 언어)를 '한국어(대한민국)'로 바꾸세요.

4

받아쓰기 언어 확인

첫 화면 파일 놓는 칸 아래의 언어 칸이 '한국어'인지 확인하세요.

5

녹음 파일 넣기

녹음·영상 파일을 칸에 끌어다 놓거나 칸을 눌러 고르면 바로 받아쓰기가 시작돼요. 끝나면 '00:05' 같은 시간과 함께 문장이 줄줄이 나와요.

6

내보내기

위쪽 '내보내기'를 누르면 받아쓴 내용을 파일로 저장할 수 있어요.

막힐 때

  • 너무 느려요
    설정 → 모델에 'CPU에서 트랜스크립션' 항목이 있어요. 켜져 있으면 느려요. 그래픽카드가 있는 PC면 꺼 두세요.
  • 틀린 단어가 있어요
    완벽하진 않아요. 저희 녹음에서도 '시안'을 '시한'으로, '초안'을 '추한'으로 적은 곳이 있었어요. 중요한 회의록은 한 번 훑어보세요.
  • 사용 기록을 보내나요?
    설정 → 개인정보에 '익명 사용 통계' 항목이 있어요. 원하지 않으면 끄세요. 녹음 자체는 내 PC에서만 처리해요.
  • 받아쓴 파일은 어디 있어요?
    설정 → 트랜스크립션 → 프로젝트 폴더(기본: 문서Vibe)에 녹음과 결과가 같이 저장돼요. 지우려면 같은 화면의 '모든 프로젝트 삭제'를 쓰세요.
